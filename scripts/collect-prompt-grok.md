# Grok への依頼文（X 上の情報の収集）

X の投稿は、こちらからは自動では読めません（ボットの拒否・ログインが要る）。X の情報を探せる Grok に、探してもらい、結果を貼ってもらう。下の「ここから」〜「ここまで」を Grok に貼る。`【テーマ】` の所だけ書き換える。DeepSearch（または X 検索）を有効にする。

**この依頼で得られるものは、二次資料（X の投稿とその要約）。** 事実・数字・条文の根拠には使わない。陳情書・要望書の文面にも入れない。使えるのは、(1) 投稿の話題・切り口の参考、(2) 一次資料を探す手がかり、だけ。貼っていただいたあと、手がかりの一次資料にこちらで当たり、確かめられたものだけを記録する（記録先：`docs/調査/Xの調査の記録/` に日付つきで）。

---ここから---

あなたは、日本の地方議会への陳情・請願と、その周辺の市民の動きを調べる調査員です。X（旧 Twitter）の公開の投稿を探して、下の作業をしてください。

## 背景
- 市民が地方議会に陳情書を出すのを手伝う、個人運営のサイトの運営者が、X に投稿する材料を集めています。団体ではありません。
- 集めたいのは、投稿の参考になる話題・切り口と、一次資料（法令の原文、官公庁・自治体・議会・裁判所・国際機関の公式資料、論文の原文）を探す手がかりです。

## 探すこと
1. 【テーマ】について、直近1年の、日本の自治体・議会・国の動き（陳情の採択、条例の制定・改正、国の通知、判決、調査の公表）を、最初に伝えた公式のアカウント（議会・自治体・省庁・裁判所・報道機関の公式）の投稿から。
2. 同じテーマで、陳情・請願・意見書を出した人や団体の投稿（出し方・つまずき・結果）。
3. 海外の請願・市民参加の制度（英国議会の電子請願、ドイツ連邦議会、欧州議会、欧州市民イニシアティブなど）について、公式のアカウントが出している説明。
4. 陳情・請願についての、よくある誤解や質問（「署名数で議会が動く」など）。

## 出力の形
次の表で出してください。1行が1つの投稿または話題です。

| 投稿のURL | 投稿の日付 | 投稿者の種類（公式／団体／個人） | 内容の要約（1〜2文） | 投稿にある事実の主張（数字・条文・日付があれば、そのまま） | 一次資料の候補（URL。開いて確かめたものだけ。確かめていなければ「（未確認）」） |
|---|---|---|---|---|---|

## 守ってほしいこと
- **実際に見つけた投稿だけを書いてください。** URL・日付・数字は、見つけたものだけ。記憶や推測で書いたものには「（未確認）」と付け、存在しない投稿・URL・数字を作らないでください。見つからなければ「見つからなかった」と書いてください。
- 投稿の文は、要約の中で引用するときも、原文のとおり短く（1投稿につき100字まで）。言い換えて事実にしないでください。
- **一般の個人のアカウント名・氏名は書かないでください。** 個人の投稿は、内容の傾向だけを書きます。公式のアカウント（議会・自治体・省庁・裁判所・報道機関・団体）は名前を書いてかまいません。
- 特定の議員・政党・自治体・個人を批判する投稿は、内容の要約にとどめ、評価や推測を加えないでください。
- 事実の主張のうち、公式の資料で確かめられなかったものは、「一次資料で確かめられていない」と書いてください。

---ここまで---

## 受け取ったあとの手順
1. 貼っていただいた表を、`docs/調査/Xの調査の記録/<日付>-<テーマ>.md` に、そのまま「Grok の回答（未確認）」として保存する。
2. 「一次資料の候補」と、投稿の事実の主張を、こちらで公式のページに当たって確かめる。X の投稿の URL は自動では開けないので、本物かどうかは運営者が1件ずつ開いて確かめる（確かめた印は「X確認済み」と付ける）。
3. 確かめられたものだけを、投稿・note の材料にする。確かめられなかったものは、その旨を残して使わない。

# B. フォロー・リストの候補（公式アカウントの一覧）

X での情報収集のため、公式アカウントの一覧を Grok に頼む。結果は、運営者が1件ずつ開いて、公式のアカウントか確かめる（Grok の回答は二次資料）。フォローはせず、まず非公開リストに入れる（[X の時間とフォローの方針](../docs/設計/Xの時間とフォローの方針.md)）。

---ここから---

あなたは、日本の自治体・議会・国の機関の、X（旧 Twitter）の公式アカウントを調べる調査員です。次のアカウントを探して、表で出してください。

探すもの：
1. 【都道府県名または市区町村名】の議会の公式アカウント、自治体（広報・広聴）の公式アカウント。
2. 国の機関：内閣府（男女共同参画局、こども家庭庁）、法務省、最高裁判所、厚生労働省、総務省、デジタル庁、国会（衆議院・参議院）の公式アカウント。
3. 【テーマ】に関する、公式・団体のアカウント（賛成・反対の両方の立場）。

出力の表：

| アカウント名（@ID） | 種類（議会／自治体／省庁／団体／報道） | 公式と判断した根拠（公式サイトからのリンクなど。開いて確かめたものだけ） | 直近1か月の投稿の頻度（目安） | 立場（団体のみ：賛成／反対／中立） |
|---|---|---|---|---|

守ってほしいこと：
- 実際に見つけたアカウントだけを書く。見つからなければ「見つからなかった」と書く。記憶や推測で ID を書かない（書くなら「（未確認）」）。
- 個人のアカウントは書かない（議員は、議会の公式ページに本人のアカウントがあると書かれているものだけ）。
- 特定のアカウントへの評価・推測を書かない。
