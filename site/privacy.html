サイトの情報の扱い（外部送信・Cookie）

このサイトを見たとき、あなたの端末から運営以外の会社のサーバーへ送られる情報と、端末に残る情報を、ここにまとめます。2026年11月24日時点。

いつも言えること

  • 広告のプログラムと、Google アナリティクスなどの外部の解析サービスは入れていません。閲覧数だけは、サイトを置いている Vercel の解析（Vercel Web Analytics）で数えています（下の表）。このサイトのページは、自分のサイトのプログラム以外を読み込まない設定にしています。
  • Cookie は使っていません。
  • 住所・氏名・陳情の文面は、あなたの端末の中だけで文書にします。運営のサーバーにも、下の会社にも送りません。

外の会社のサーバーへ通信するところ

ページを開く、または画面で操作すると、次の通信が起きます。どれも、通信の相手には、通信のしくみ上かならず届く情報（あなたの IP アドレス、ブラウザの種類、見ているサイトの名前）が届きます。

どこで送る先送る情報と、使いみち
どのページでも、開いたときこのサイトのサーバー（Vercel）の閲覧数の解析（Vercel Web Analytics）開いたページの URL などを送り、ページごとの閲覧数を数えます（送る項目の細かい一覧は、Vercel の説明で確かめきれていません）。Cookie は使いません。Vercel の説明では、訪問者の区別にはリクエストから作った値を使い、24時間で捨てるとされています（Vercel の説明）。数字を見られるのは運営者だけで、個人を特定するためには使いません。
トップページ（/）を開いたときSupabase（データベースの会社）こちらから送る内容はありません。「これまでの歩み」の数（提出の報告の件数）を読み出すだけです。
各テーマの作成画面（例：/kodomo/make）で、議会・自治体を選ぶ画面Supabaseこちらから送る内容はありません。ほかの人が報告した、議会ごとの提出の数と、寄せられた情報を読み出します。「出したら押す」を押したときだけ、押した議会・件数・（任意で）項目の報告を送ります。氏名・住所は送りません。
/feedback（ご意見のページ）Supabase開いたとき：公開している質問と答えを読み出します。送信ボタンを押したとき：書いたご意見（と、付けた資料）を送ります。
各テーマの作成画面の「署名して出す」の、国の意見募集の案内このサイトのサーバー（Vercel）テーマの語（例：子ども）を、このサイトのサーバーへ送り、国の意見募集の一覧（e-Gov）から絞った結果を受け取ります。氏名・住所は送りません。e-Gov への問い合わせはサーバーが行い、あなたの情報は付きません。
トップページの「最近の更新」このサイトのサーバー（Vercel）こちらから送る内容はありません。サーバーが GitHub の公開の更新履歴を読み、結果を返します。
各テーマの作成画面の、関連の本・グッズの欄Amazon（商品の画像の配信元）欄が表示されると、本の表紙画像を Amazon から読み込みます。こちらから送る内容はありませんが、通信の相手の Amazon には上の基本の情報が届きます。Amazon 側での扱いは、Amazon のプライバシーの案内によります。リンクを押して Amazon へ移ったあとは、Amazon のサイトの扱いになります。

上の会社への通信は、あなたの端末に残っている Cookie や ID を取り出して送るものではありません。このサイトが指定していない情報（ログイン情報など）も送りません。

あなたの端末に残るもの（外へは送りません）

このサイトは、ブラウザの「ローカルストレージ」に、次のものを残します。外部には送りません。ブラウザの設定で消せます。

  • 作成画面の入力の途中（下書き）、文面の手直し、最近選んだ議会
  • 「住所・氏名を覚えておく」にチェックしたときの住所・氏名（初めは覚えません）
  • 「出したら押す」を押した議会の目印（二重に押さないため）
  • 使う生成 AI の選択（おまかせ画面）

確かめられていないこと

  • 電気通信事業法の「外部送信規律」（第27条の12）は、電気通信事業を営む人が一定のサービスで情報を外へ送るときに、通知か公表を求めるものです。総務省のFAQ（問1-8）は、電気通信事業を営んでいない場合は対象にならないとしています。このサイトの運営が対象に当たるかは、まだ確かめられていません。当たるかどうかにかかわらず、利用者にわかるよう、この一覧を載せています。
  • 上の「どこで」の一覧は、運営がサイトのプログラムを確かめたものです。ご覧のブラウザの拡張機能などが足す通信は、ここには含みません。
