陳情アクション ＞ 運営が困っていること ＞ 人口カバー率

やり方がわかっている自治体（人口カバー率）

陳情（議会あて）・要望（知事・市区町村長あて）・パブリックコメント（意見募集）について、出し方を公式サイトで確かめられた自治体が、人口でみてどれだけを占めるかです。住民の多い自治体から順に調べています。

出典の照合：準備中（根拠にした公式サイトの一文が、いまもそのページに載っているかを機械で確かめます。毎月と、議員の改選のあとに行います）

いまのカバー率

JavaScript を有効にすると表示されます。

  • 出し方までわかる：持参・郵送・メール・電子申請・FAX のどれかの扱いを、公式サイトか事務局の回答で確かめた自治体です。
  • 案内ページはある：出し方の案内ページは見つかっているが、扱いまでは読み取れていない自治体を含みます。
  • パブリックコメント：意見募集の一覧・案内のページが見つかっている自治体です。
  • 人口は総務省「住民基本台帳に基づく人口」（令和8年1月1日現在）。市区町村の割合は、全市区町村の人口の合計に対する割合です（東京23区は区ごとに数えます）。

陳情が、議員や市長の側に届くのかを教えてください

「陳情を出すと、どこまで届くのか」を、数字で言えるようにしたいと考えています。いま確かめられているのは、次のとおりです（2026年11月23日時点。公式サイトの案内で確かめたもの）。

  • 議員に届くと確かめられた議会：264（審査する140・配付や閲覧だけ124。全1787議会のうち）。このうち、公式サイトにはっきり書いてある、または議会事務局の回答で確かめたのは243で、残りの21は、文面から推し量ったものです。数え方は node scripts/intake-reach.js（住民の陳情について、どの出し方かで「審査」なら審査、そうでなく「配付・閲覧だけ」なら配付だけに数え、1議会は1つにだけ数える）。
  • 市長・知事などの執行機関にも写しが届くと、公式サイトにはっきり書いてある議会：3（千葉県・東京都小平市・福岡県久留米市。出典は調査記録）。文面から推し量れるものを入れても10です。
  • 残りの議会は、まだ確かめられていません。審査せず配付だけの議会もあるので、「どの陳情も市長が見る」とは言えません。

お住まいの議会の案内ページ（「請願・陳情」「陳情の取り扱い」など）に、次のことが書いてあれば、教えてください。

  1. 陳情は、委員会で審査されるか、議員に配られるだけか。
  2. 陳情の写しや結果が、市長・知事などの執行機関（担当部署）にも送られるか。送られるのは、すべての陳情か、採択されたものだけか。
  3. 陳情書に参考資料を添える（議員に配ってもらう）とき、何部出すよう決まっているか（議員の人数分、30部など）。電子データなら部数が減るか。 確かめられたのは12議会です（2026年11月23日に公式ページで確かめた。議会ごとに部数が違い、5部から100部まであります）：厚木市30部（電子データなら2部）・三田市30部（意見陳述の資料は31部＝原本1＋写し30）・白井市30部・国立市25部・茅ヶ崎市20部・伊勢原市21部・小金井市50部（担当委員のみなら25部）・板橋区100部・三浦市5部・大和市28部（議員分）・小田原市35部・相模原市46部（データなら1部）。 習志野市は、PDF（A3まで）にできる資料は電子で配られ、PDF にできない大きい紙や冊子だけ、紙で30部です。日野市は、添付された資料は議員に配られません。
  4. 書いてあるページの URL と、その一文。

議会の扱いを知らせる（ご意見のページの入力欄が開きます）

議会に電話で確かめた場合は、議会への出し方を確かめるページからも送れます。運営が原文を読んで確かめたものだけを、数字に入れます。氏名・住所・連絡先は書かないでください。

まだわからない自治体の確認をお願いします

お住まいの自治体や、送りたい議会が下の一覧にあれば、公式サイトの案内ページを探して、URL を教えてください。運営が原文を読んで確かめてから反映します。

  1. 一覧の「知らせる」を押すと、ご意見のページの入力欄に自治体名が入った状態で開きます。
  2. 見つけた案内ページの URL を「根拠の資料の URL」に入れて送ってください。わかる範囲で、郵送・メール・電子申請で受け付けるか、住民以外も出せるかを書き添えてもらえると助かります。
  3. 議会に電話で確かめた場合は、議会への出し方を確かめるページからも送れます。

氏名・住所・連絡先は書かないでください。
