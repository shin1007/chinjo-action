# 陳情の意義を、わかりやすい言葉で書く（中学生でも読める水準）

## 出てくる場所

- 一覧：`/<テーマ>/easy`（例：/kodomo/easy）
- 1項目：`/<テーマ>/easy/<項目id>`（例：/kodomo/easy/n_restore）
- 関連資料のページ（`/<テーマ>/refs`）の各項目の中にも「わかりやすい言葉で読む」へのリンクが出る

## 書く場所と形

`site/themes/<テーマ>/easy.js` に、項目の id ごとに4つの欄を書く。

```js
window.EASY = Object.assign(window.EASY || {}, {
  n_restore: {
    what: 'この陳情でお願いすること（1〜2文）',
    now: 'いまは、どうなっているか（2〜4文）',
    why: 'どうして困るのか・なぜ大事か（2〜4文）',
    after: '変わると、だれにとって何がよくなるか（1〜3文）',
  },
});
```

書いたら `node scripts/easy.js` でページを作り、`node scripts/pages.js`・`npm test` を通す。

## 守ること

1. **事実は、その項目の `reason`（陳情の理由）と `refs`（参考資料）、`figs`（数字）にあることだけを使う。** 新しい数字・条文・出来事を足さない。足したいときは、先に一次資料で確かめて `reason`・`refs` に入れてから
2. **数字は丸めすぎない。** 「約2万人」のように丸めるときは、元の数字と同じ資料・同じ年のものにする。年を書く
3. **中学生が読める言葉にする。** 1文は60字くらいまで。法律の名前・専門用語は、初めて出るところで短く言いかえる（例：「親権（子どもを育て、守るための親の権利と責任）」）。漢字は中学校で習う範囲を目安に、むずかしい語は言いかえる
4. **相手をおとしめない。** 特定の人・団体・性別・国籍の人を悪く言う書き方をしない。「〜な人たちが悪い」ではなく「〜のしくみが足りない」と書く
5. **反対の考えがあることにふれてよい。** 意見が分かれる項目は、`why` の最後に「〜という心配の声もあります」と1文入れてよい（その声の出どころが refs にあるときだけ）
6. **あおらない。** 「絶対」「ひどい」「許せない」などの強い言葉や、感嘆符を使わない
7. **陳情（議会へのお願い）と法律の改正のちがいを混ぜない。** 国への意見書を求める項目（scope: national）は「議会から国に意見を伝えてもらう」、自治体あての項目（scope: local）は「市や町に取り組んでもらう」と書き分ける
8. 書いていない項目のページは「準備中」と出る（作らないのではなく、準備中として出す）

## 見直しのしかた

- `reason` と見比べて、言っていないことを言っていないか
- 中学1年生が一人で読んで、「何をお願いしているか」を1文で言えるか
- 数字・年が `reason`・`figs` と同じか
