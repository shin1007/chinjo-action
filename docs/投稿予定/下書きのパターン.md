## 5. 海外（F）— 確かめたものだけ

根拠：[海外の請願制度](../調査/海外の請願制度.md)。日本の制度と同じものとして書かない。

**5-a 英国**
```
英国議会の電子請願：署名1万で政府が回答、10万で議会で討論されうる（委員会が見送ることもあります）。
日本の陳情・請願には、署名数で回答が決まる仕組みは、確かめた範囲ではありません。
```

**5-b ドイツ**
```
ドイツ基本法第17条：「誰でも、1人でも共同でも、書面で、所管の機関と議会に請願できる」。
連邦議会の請願委員会は、公開請願に6週間、ほかの人が共同署名できるようにしています。
```

**5-c EU**
```
EUの市民イニシアティブ：100万人以上、7か国以上でそれぞれの下限の署名を、12か月で集めます。
提出後は、6か月以内に欧州委員会が対応と理由を示します。
日本の陳情とは、規模も仕組みも別ものです。
```
