# チームみらいへの政策提言（2026年11月26日）

- 窓口：チームみらい「政策についてのご意見」AIインタビュー https://interview.team-mir.ai/interview/policy-request
- 出し方：テキストで回答。**公開せずに提出**（公開すると全文が載り、あとから書き換えられないため）。ログインはしていない。
- 内容：地方議会への陳情・請願の受け付け方について
  1. 各議会が受け付け方（持参・郵送・メール・電子申請・FAX、住民以外、郵送やメールの陳情を審査するか配るだけか、結果の通知、氏名の公開）を共通の項目で公式サイトに載せる。総務省が項目の見本を示し、機械で読める形で出す。
  2. 郵送・メールの陳情を「配るだけ」にするなら、理由と扱いを事前に明示し、出した人に知らせる。
  3. 電子申請（本人確認つき）で出せるようにし、紙と同じく審査の対象にする。
