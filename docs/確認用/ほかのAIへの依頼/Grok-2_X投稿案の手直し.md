添付は、市民が地方議会に陳情書を出すのを手伝うサイトを紹介し、使いやすさの意見を集めるために X に投稿する文の案です。

## 読んでほしい人

日本の国内の問題に関心はあるが、自分から動くのは億劫に感じている人。陳情という言葉もあまり知りません。

## してほしいこと

1. それぞれの案について、X でこの人たちの目に留まり、リンクを押してもらえそうかを、理由とともに5段階で評価してください。
2. 押してもらいにくい案は、直した文を出してください。X の文字数（全角140字）に収めます。
3. 政治的な対立を招きそうな言い方（特定の政党・団体・人への批判に読めるもの）があれば、指摘して言い換えてください。
4. 似た目的の投稿で、実際によく反応されているものの特徴（書き出し、画像、ハッシュタグ、投稿する時間帯など）があれば、見つけた投稿の URL を付けて挙げてください。見つからなければ「見つからなかった」と書いてください。
