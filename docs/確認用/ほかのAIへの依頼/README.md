# ほかの AI への依頼

Claude が苦手なところを、Grok（無料プラン）と Gemini（安いプラン）に補ってもらうための依頼文です。

## 使い分け

| | 得意なこと | このプロジェクトで頼むこと |
|---|---|---|
| Gemini | Google 検索を使った調べもの、長い資料をまとめて読む、画像（スクリーンショット）を見る | 議会の会議録・採択結果の検索（Claude はボット拒否や画像のPDFで読めないことが多い）、画面の使いやすさの点検、長い文面の読みやすさの点検 |
| Grok | X（旧Twitter）の投稿を探して読む、今の話題 | 一般の人が陳情や各テーマをどう話しているか、Xに投稿する文の手直し |

Claude が苦手なのは、ボットを拒否するサイト・画像だけのPDF・Xの投稿・実際の利用者の感じ方です。上の依頼はそこを補うものです。

## 返事の置き場所

返事は、そのまま全部を [返事/](返事/) に `日付_相手_番号.md`（例：`2026-11-13_Gemini-1_男女平等.md`）で保存して、Claude に「返事を置いた」と伝えてください。
Claude が一次資料に当たって確かめてから、サイトに入れるかを決めます（AI の返事だけで文面は直しません）。
