# Gemini への依頼 3：陳情書の文面の読みやすさと説得力

`docs/確認用/見本/` からテーマの .md を1つ添付し、下の依頼文を貼ります（1回に1テーマ）。

---ここから---

添付は、市民が地方議会に出す陳情書の文面の見本です。サイトが自動で作るもので、内容ごとに1通ずつ並んでいます（件名・趣旨・記・理由・参考資料）。

## 読む人

- 陳情書を審査する市区町村議会の議員（委員会で採択・不採択を決める）
- 議員に説明する議会事務局・担当課の職員

## してほしいこと

議員の立場で読み、次を挙げてください。

1. **読みにくいところ**：1文が長すぎる、専門用語の説明がない、同じことの繰り返し、結論が後ろにある、など。項目の番号と該当する文を引用して。
2. **採択されにくくしている書き方**：断定が強すぎる、特定の立場への批判に読める、自治体の権限を超えたことを求めている、費用や事務の負担に触れていない、など。
3. **足りない一言**：議員が「なぜこの自治体で、今なのか」を納得するために足すとよいこと（他の自治体の例、住民への効果など）。ただし、新しい事実や数字を足す提案には、出典（公式の資料）を必ず付け、確かめていないものは「（未確認）」としてください。
4. **言い換えの案**：1〜2で挙げた文について、直した文の案。

## 守ってほしいこと

- 文面の主張そのものの是非（賛成・反対）は評価しないでください。伝わり方と、議会での通りやすさだけを見てください。
- 参考資料の中身の正しさは、この依頼では点検しなくてかまいません。

## 答え方

項目ごとに見出しを立て、1〜4を箇条書きで。最後に、全体に共通する直し方を5つまでまとめてください。
