# Gemini への依頼 2：スマホの画面の使いやすさ

スマホで https://chinjo-action.vercel.app/kenko/make を開き、内容を選ぶ → 自治体 → あなた → 文面確認 → 署名して出す、まで進めながらスクリーンショットを撮って（5〜8枚、各画面の上から下まで）、下の依頼文と一緒に貼ります。

添付は、市民が地方議会に陳情書を出すのを手伝うウェブサイトの、陳情書をつくる画面をスマホで最後まで進めたときのスクリーンショットです（上から順に、画面の流れのとおり）。

## このサイトの利用者

日本の国内の問題に関心はあるが、自分から動くのは億劫に感じている人です。議会や陳情の手続きはほとんど知りません。スマホで、すき間の時間に見ることが多いと考えています。

## してほしいこと

この利用者になったつもりで、画面を1枚ずつ見て、次を挙げてください。

1. **やめたくなるところ**：読む量が多い、何をすればよいか分からない、難しい言葉、不安になる書き方など。画面の番号と、該当する文や部品を具体的に。
2. **見落としそうなところ**：大事なのに目立たない、下のほうに埋もれているボタンや注意書き。
3. **押し間違えそうなところ**：ボタンが小さい・近い、どれを押せばよいか迷う。
4. **直し方の案**：それぞれについて、文の言い換えや、並べ方・見せ方の案を1つずつ。大きな作り直しではなく、すぐできる直しを優先してください。
5. **良いところ**：変えないほうがよいところも、あれば短く。

## 答え方

- 画面ごとに見出しを立て、上の1〜5を箇条書きで。
- 最後に、影響が大きい順に「直すべきこと トップ5」をまとめてください。
- 画面に写っていないことは推測で書かず、「写っていないので分からない」としてください。
