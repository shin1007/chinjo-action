## 設計の方針（固めたところ。確かめた結果で変える）
1. 窓口を2種類に分ける。A「見返りのない応援」と B「対価のある有料質問」。`support.json` の `methods` に `kind`（`gift` / `paid`）を足し、ページでは別々の見出しで並べる。
2. 窓口は1つに頼らない。BMC が 404 のように止まりうるので、A を最低2つ（例：国内の応援サービス＋PayPal.Me または GitHub Sponsors）、B を1つ持つ。ただし規約を読んで使えるとわかったものだけを `methods` に足す。足していない窓口は表示されない。
3. 集まり具合は、窓口ごとの内訳を持たず、合計だけを毎月手で更新する（`collected`）。目標額（`goal`）は、生成AI の利用料の請求書の額を根拠にする。請求書の額と、集まった額（手数料を引く前か後か）の数え方をページに書く。
4. ランキングは A だけを対象にする。B（有料質問）は匿名で使えることが価値なので、載せない。名前の掲載は「ランキング希望」の書き添えがあった人だけ（今のまま）。
5. 自動で数える仕組み（Stripe などの API）は、窓口が決まって手作業が負担になってから足す。

### 法人・団体向けの「スポンサー枠」案（利用者からのご意見）
- 案の中身：フッターやトップの目立たない場所に「この社会インフラを応援する企業・団体様へ（月額5,000円〜、バナー・お名前掲載）」の専用モーダルを置く。Stripe の定期課金のリンクを置き、決済のあとにロゴ画像とリンク先 URL を送るフォームへ進める。ねらいは、行政書士・弁護士事務所、市民団体、社会課題に関心のある IT 企業。
- 見込みと注意（どれも一次資料ではまだ確かめていない。考え方の整理）：
  - 利点：個人の応援より単価が高く、継続しやすい。名前を出す側が自分で選ぶので、個人の応援者のような負担が小さい。
  - サイトの約束との整合：スポンサーには「陳情の内容・参考資料の判断に口出しできない」「掲載は広告であって推薦ではない」と明記する。掲載の基準（掲載しない業種：政党・政治団体、特定の議員・候補者、陳情の対象と利害の強い事業者など）を先に決める。
  - 士業の掲載：弁護士・行政書士は、広告の規則（弁護士の業務広告の規程、行政書士会の規則など）がある。サイトが事務所を「紹介・推薦」する形になると、非弁行為・紹介料の禁止に近づくおそれがある。一括の掲載料（定額の枠）に限り、相談の紹介や成果に応じた手数料は取らない形にする。各法令・規程の原文で確かめるまで、士業の募集は始めない。
  - 窓口：Stripe は個人への寄付を禁止業種としている。スポンサー料は「広告の対価」なので事情が違うが、個人事業として受けられるか、定期課金の審査を、Stripe に問い合わせて確かめる（上の Stripe の節の問い合わせと同時に）。
  - 税・表記：広告の売上は寄付と違って事業収入になる。税務署・税理士に確かめる。特定商取引法に基づく表記に、枠の内容・契約期間・解約・返金を書き足す（事業者向けの取引でも書くかは未確認）。
  - 運用：ロゴとリンクの審査（反社会的勢力・違法・誤解を招く内容でないか、リンク先の確認）、解約時の取り下げ、掲載中のリンク先が変わっていないかの定期確認が要る。手作業で足りる件数に抑える。
  - 政治的中立：陳情は議会に出すものなので、スポンサーが政治的に偏って見えないよう、「応援（広告）であって、サイトの主張ではない」と明記する。

### 調べた結果（2026-11-15。原文を開いて確かめたもの）
- **Stripe（日本）**：「管轄区域固有の禁止業種」の「日本」の欄に「個人への寄付」がある（https://stripe.com/jp/legal/restricted-businesses 、2026-11-15 に取得。ページ内に最終更新日の表示は見つからず）。同じページの冒頭は「政治的見解や所属に基づいてサービスへのアクセスを制限することはない」と述べている。「圧力団体および政治組織」はインドの欄で、日本の欄にはない。→ **寄付は個人では受けられない見込みが高い。スポンサー料（広告の対価）は寄付ではないが、個人事業として審査を通るかは、規約の文面からは決められない。Stripe への問い合わせは残る。**
- **弁護士法**（e-Gov、2025-10-01 施行時点の版）：第27条は、弁護士が第72条から第74条までに違反する者から事件の周旋を受けることを禁じる。第72条は、弁護士でない者が報酬を得る目的で法律事件の鑑定・代理・和解などの法律事務や**その周旋**を業とすることを禁じる。→ このサイトが士業の事務所を利用者に紹介して手数料を取れば、周旋に当たるおそれが大きい。**定額の広告枠に限り、紹介・成果報酬は取らない**方針を、掲載規約に書く。
- **日弁連「業務広告に関する指針」**（令和3年改正の版。https://www.nichibenren.or.jp/library/pdf/jfba_info/rules/other/shishin_kaiki_44.pdf ）：弁護士法第72〜74条に違反する疑いのある者との提携の実態がある弁護士の広告や、**他士業その他弁護士でない者と正当な理由なく報酬を分配する実態**がある弁護士の広告は、規程に違反する例とされる。→ 弁護士が定額の掲載料を払って載るだけなら、この例には当たらない見込みだが、**報酬の分配や紹介料の形に見えない**よう、料金は月額・年額の定額に固定する。比較広告・誇大広告の規制もあり、載せる文面は弁護士側の責任とする。**規程の本文（会規第44号）は、PDF を取得したが条文までは読んでいない。**
- **行政書士法**（e-Gov、2026-05-21 施行時点の版）：第1条の3は、報酬を得て官公署に提出する書類を作成することを行政書士の業務とし、第19条は、行政書士でない者が報酬を得て業としてこれを行うことを禁じる。→ **このサイトが「陳情書の作成」を有償で請け負う形（受託）は、行政書士法第19条に触れるおそれがある**。陳情書そのものを有償で作ること、スポンサーが書類作成の代行をうたうことは避ける。カスタム版は、サイトの仕組み（フォームやひな形のシステム）を提供するもので、個々の書類の作成は引き受けない形に限る。行政書士の広告の規則は、日本行政書士会連合会の原文をまだ読んでいない。
- **特定商取引法**（e-Gov、2026-08-12 施行時点の版）：第26条第1項第1号により、**営業のために・営業として契約する相手への販売・役務提供には、通信販売の規定（広告の表示事項を定めた第11条など）が適用されない**。→ 法人・団体のスポンサー契約は、事業者向けの取引なので、表記の義務の対象外になる見込み。ただし、個人（士業の個人事務所を含む）が営業のためでなく契約する場合は別。契約の申込みの画面で「事業者の方のみ」と明記し、迷う場合は /tokushoho に載せておく。
- **公職選挙法**（e-Gov、2026-09-03 施行時点の版）：第199条の2は、公職の候補者等（公職にある者を含む）が、選挙区内の者に、いかなる名義でも**寄附**をすることを禁じる（政党・親族などへの例外あり）。→ 議員が料金を払って作った専用の陳情フォームを、議員の名前で選挙区の住民に**無料で**提供すると、役務の無償提供が寄附に当たるかの問題が出うる。**条文の但書き以降と、役務の提供が寄附に当たるかの解釈（総務省の解説・選挙管理委員会の見解）は読んでいない。** 議員が窓口になるカスタム版は、受けないか、総務省・選挙管理委員会に確かめてからにする。
- **税**：検索の結果に、税務大学校の論叢（寄付型クラウドファンディングの消費税）が出た。寄付に対価性がなければ消費税の対象外、個人が受け取る場合は個人からなら贈与税・法人からなら所得税の問題になる、という整理。**検索の要約を読んだだけで、論文の原文は開いていない。** スポンサー料は対価のある広告なので事業所得（または雑所得）・消費税の問題になる。税務署・税理士への確認は残る。

### 「団体・議員・自治体向けカスタム版」の問い合わせ窓口（利用者からのご意見）
- 案の中身：「地域の課題に特化した専用の陳情フォームを作りたい議員・市民団体の方へ」という窓口を置き、カスタム導入（初期費用＋月額の保守）の受託につなげる。
- 見込みと注意：
  - 受託は、サイトの運営方針（無料で、一次資料にもとづく文面）と別の事業になる。運営者の時間が足りなくなる。生成AI の費用は自費で払っているので、受託の売上で運営費をまかなう、という筋は立つ。
  - 議員・自治体向けは、公職選挙法・政治資金の扱い、自治体の契約の手続き（入札・随意契約）に関わるおそれがある。議員が自分の陳情の窓口に使う形は、請願・陳情の趣旨（住民が議会へ出すもの）と食い違わないかを確かめる。
  - 政党・特定の議員の宣伝に見えると、サイトの政治的中立の信用を失う。受けるのは、市民団体・NPO・自治会など、特定の候補者・政党と結びつかない相手に限る案も考えられる。
  - 成果物（専用のテーマ）の文面の責任（根拠は一次資料で確かめる、という方針）をどこまで守るかを、契約のひな形に入れる。
