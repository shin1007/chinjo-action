## 設計の方針（固めたところ。確かめた結果で変える）
1. 窓口を2種類に分ける。A「見返りのない応援」と B「対価のある有料質問」。`support.json` の `methods` に `kind`（`gift` / `paid`）を足し、ページでは別々の見出しで並べる。
2. 窓口は1つに頼らない。BMC が 404 のように止まりうるので、A を最低2つ（例：国内の応援サービス＋PayPal.Me または GitHub Sponsors）、B を1つ持つ。ただし規約を読んで使えるとわかったものだけを `methods` に足す。足していない窓口は表示されない。
3. 集まり具合は、窓口ごとの内訳を持たず、合計だけを毎月手で更新する（`collected`）。目標額（`goal`）は、生成AI の利用料の請求書の額を根拠にする。請求書の額と、集まった額（手数料を引く前か後か）の数え方をページに書く。
4. ランキングは A だけを対象にする。B（有料質問）は匿名で使えることが価値なので、載せない。名前の掲載は「ランキング希望」の書き添えがあった人だけ（今のまま）。
5. 自動で数える仕組み（Stripe などの API）は、窓口が決まって手作業が負担になってから足す。
