# 陳情・要望の出し方のまとめ

議会の「陳情の案内ページ」と、知事・市区町村長の「要望（手紙・市民の声）の案内ページ」を読んで、どう出せば受け付けられ、審査・回答されやすいかをまとめたもの（2026-11-12）。

## 調べ方

- 議会：site/data/sites.js の陳情・請願の案内ページのうち、人口の多い順に260件を取得し、248件が読めた（14件は取得できず。うち刈谷市・東村山市・日立市などは 403）。これとは別に、郵送の扱いは site/data/mail.js の180議会（原文で一つずつ確かめたもの）を使った。
- 首長：site/data/request-pages.js の先頭（都道府県→政令市→人口順）200件を取得し、194件が読めた。
- 件数は、ページの文からキーワードで拾った数。書いてあっても言い回しが違えば拾えていないので、**下限の目安**として読む。例の文は、各ページの原文のまま。

## 1　議会に陳情を出すとき

### 1-1　郵送で出して審査されるか（180議会、原文で確認済み）

| 扱い | 議会の数 |
|---|---|
| 郵送でも審査される（ok） | 62 |
| 審査には持参が必要（郵送は配付・議長預かりだけ） | 45 |
| 住民以外からのもの（または市外からの郵送）は配付だけ | 14 |
| 出し方に関わらず、陳情は配付だけ（審査しない） | 59 |

- 郵送でそのまま審査されるのは約3分の1。**住んでいる議会なら持参がいちばん確実**。
- 持参が必要な議会でも、電子申請なら審査される議会がある（帯広市「直接持参したもの又は電子申請システムにより提出したもの」）。逆に、秦野市は郵送も電子申請も「議員へ配付の取り扱い」。
- 小田原市は「持参が困難な場合は、議会局までご相談ください」と書いており、事情を伝えれば扱いが変わる余地がある。
- 立川市は、郵送・オンラインでも陳情者と内容の確認がとれ、委員会の当日に陳情者が説明に来られれば審査、来られなければ参考配付（[案内](https://www.city.tachikawa.lg.jp/shigikai/gian/1007179.html)）。

### 1-2　市外から出すとき

市外の人の陳情を配付だけにする議会がある（拾えたのは24ページ）。ただし、つながりがあれば審査する例もある。

- 我孫子市：「陳情者が市との係わりが深い場合（市内在勤・在学等）は、議題とし所管の委員会において審査」（[案内](https://www.city.abiko.chiba.jp/shisei/shigikai/shimin_shigikai.html)）
- 千葉市：除くのは「市外から提出・郵送されたもの（近隣市等の住民から提出・郵送された陳情で、願意が本市に関わる内容であると議長が認めたものを除く。）」（[案内](https://www.city.chiba.jp/shigikai/seitin-goannai.html)）
- 習志野市：市外の陳情は原則配付だが「議会運営委員会において、1会派でも会議に付すべきという提案があれば、付議する」
- 函館市：市外からの郵送は委員会に写しを配付し、「陳情者への通知は行いません」

→ 市外から出すなら、在勤・在学などのつながりを本文に書くと審査される余地が増える。

### 1-3　締切

- 締切は「定例会の開会（招集・告示）日の何日前」や「議会運営委員会の何日前」で決めている議会が多い。site/data/councils.js の締切の注記219件のうち、日数を読み取れたものは**2日前〜15日前**に散らばっている（招集7日前が7件、議会運営委員会2日前が6件など）。
- 郵送は「必着」の議会が多い（千葉市「締切日時必着」、多摩市「締切日の昼12時必着」）。郵送やオンラインは確認の時間を取るため締切を早めている議会もある（立川市は郵送・オンラインだけ「定例会初日の10日前(必着)」）。
- 締切を過ぎたものは次の定例会に回る、と書く議会が多い。

→ **定例会（多くは2・3月、6月、9月、12月）が開く日の3週間前までに届くように出す**のが安全。

### 1-4　書き方で求められていること

| 求められていること | 拾えたページ数 | 原文の例 |
|---|---|---|
| 日本語（邦文）で書く | 111 | 三重県議会「請願書は、邦文を用いた文章によること。」 |
| 署名、または記名して押印 | 101 | 押印を不要とする議会も増えている（三重県議会「※　押印は不要です。」、我孫子市「署名の場合は押印は必要ありませんが、記名の場合は押印が必要」） |
| 連名なら署名簿を添える | 54 | 宝塚市「署名簿がある場合は本文の後に添付してください。」 |
| 電話番号・連絡先を書く | 25 | 船橋市「別紙に請願（陳情）者の連絡先の電話番号を記載し、必ず添えてください。」、習志野市は電話番号がないと「審査できません」 |
| A4の用紙 | 24 | 千葉県議会「一般的にはA4判2枚以内程度で明確かつ簡潔に」 |
| 1件に1つの事項（所管の委員会が分かれるものは分ける） | 13 | 宝塚市「1つの請願書で取り扱う趣旨は1つの事項のみとし、趣旨が異なる事項については、別の請願書でお願いします。」、新座市「土木、福祉、教育など多種類にわたる場合は…分類して別々の請願書（陳情書）に」 |
| 国などへの意見書を求めるなら、意見書の案を添える | 11 | 浦安市「意見書（案）を請願（陳情）書に添えて提出してください。意見書には、国会（衆・参議院議長）や関係行政庁（例：総務大臣など）の提出先を記載してください。」、今治市・習志野市・千葉市も同じ趣旨 |
| 部数は原本1部 | 18 | 千葉市「議長あてに1部を提出」。議員に配る資料は議会の数だけ（習志野市30部、小田原市35部） |
| FAX・メールでは出せない | 8 | 所沢市「ＦＡＸ又は電子メールでの提出は受け付けておりません。」 |

### 1-5　提出者の名前と住所が公開されること

拾えたのは47ページ。住所・氏名は文書表や会議録に載り、情報公開の対象になるのが普通（旭川市、佐賀県議会など）。一方で、ウェブには載せない・住所の一部を隠す議会もある（市川市「提出者の氏名及び住所を削除した文書表」、船橋市は令和8年第2回定例会から住所の丁目以降・町名以降を黒塗り）。西宮市は逆に「氏名・住所（町名まで）をホームページで公開」。

→ 出す人に「名前と住所は公開されるのが前提」と伝える必要がある。

### 1-6　意見陳述（委員会で説明できる）

拾えたのは34ページ。希望すれば委員会で趣旨を説明できる議会がある（我孫子市「意見陳述（5分以内）」、新座市、江別市、甲府市など）。多くは**提出のときに申し出る**必要がある（甲府市「請願・陳情を提出する際に申し出て」、新座市は意見陳述申出書）。

### 1-7　審査されない内容

議会ごとに「審査しない・配付だけにする」基準がある（今治市の陳情取扱基準、出雲市など）。よく挙がるもの：

- 裁判で争っている事件・私人間の争い・特定の個人の名誉に関わるもの
- 特定の個人・団体への誹謗中傷
- 国の事務・外交などで、その市との利害が薄いもの（今治市「国及び他の地方公共団体の事務に関するもののうち、市民の利害が密接に関連していると認めがたいもの」）
- すでに同じ趣旨の陳情に結論が出てから1年以内のもの
- **意見書の提出を求める陳情そのもの**を審査しない議会もある（出雲市「⑿ 意見書の提出を求める内容の陳情」）

→ 国への意見書を求める陳情は、その市の住民の暮らしにどう関わるかを理由に書くと、国の事務を理由に外されにくい。

## 2　知事・市区町村長に要望を出すとき（手紙・市民の声）

### 2-1　受け付ける方法（194ページ）

| 方法 | 拾えたページ数 |
|---|---|
| 窓口・投書箱 | 134 |
| FAX | 125 |
| 郵送・はがき・手紙 | 123 |
| 入力フォーム・電子申請 | 101 |
| 電子メール | 64 |

議会と違い、FAXやメールでも受け付けるところが多い。入力フォームは**字数の制限**があることがある（島根県「１回につき、１つのご提案を３００字以内」、富山県400字以内、甲府市・大垣市1,000字以内）。長い要望書は郵送か、PDFを添付できる方法で出す。

### 2-2　回答をもらうには

- 回答を希望すると書き、**氏名・住所・連絡先**を正確に書く（姫路市「回答の要否欄で「回答が必要」にチェック…未記入であったり、正しく記入いただいていなかった場合は、回答をいたしかねます」）。
- 匿名だと回答しないところが多い（柏市「住所、氏名、電話番号が不明確なものや、匿名のもの」は回答しない、所沢市も同じ）。姫路市のように匿名でも受け付けて担当課に回すところもある。
- 回答までの日数は1週間〜3週間程度（山梨県「1週間以内に回答」、浦安市「2週間程度」、新座市「3週間ほど」、岐阜市「20日間ほど」）。

### 2-3　回答されない内容

拾えたのは121ページ。誹謗中傷・営業目的・趣旨が不明なもののほか、**国や他の自治体の事務**は回答しないと明記しているところがある。

- 京都府「国や市町村などに関わるもの…については回答できません」（[案内](https://www.pref.kyoto.jp/teian/)）
- 神戸市「国際情勢や社会情勢など、本市と直接関わりのない投稿には回答できません」
- 伊丹市「県政や国政など市政以外の内容につきましては、直接当該機関へお願いします」

→ 首長への要望には、**その自治体ができること**（市の事業・窓口・研修など）だけを書く。国の制度を変えてほしいことは、議会への陳情（国への意見書を求める形）に回す。

### 2-4　対象者・公開

- 対象を住民・在勤・在学に限るところがある（所沢市「原則として市内に在住、在勤、在学等で当市に関係のある個人の方」、枚方市、宇部市、久喜市）。
- 内容と回答を要約してウェブに載せることがある（64ページ。松戸市は「公開しても良いと意思表示されているもの」だけ）。公開してほしくなければその旨を書く（三重県「掲載させていただくことに支障のある場合は、その旨をご記載いただく」）。
- 千葉市は「法人やその他の団体からの陳情・要望等につきましても、こちらの制度をご利用ください」としている（[市長への手紙](https://www.city.chiba.jp/sogoseisaku/shichokoshitsu/kohokocho/tegami.html)）。

## 3　サイトの出し方メモ・作成画面に反映するとよいこと（案）

今の出し方メモ（docs/確認用/見本/出し方メモ.md）と比べて、足りないもの。

2026-11-12 に反映：1（締切は各議会の定例会の開会日を基準にする。定例会の月が分かった議会は site/data/sessions.js に入れ、出し方メモに出す。いまは16議会）、3（意見書の案を別紙で付けられる。前文は項目の理由をそのまま使っていて、である調への書き直しはまだ）、8のうち回答の希望（要望書で選べる。選ばなければ入らない）。電話番号は、陳情書は公開されるので本文には入れず、送付状に入れる今のままにした。

1. **締切**：「定例会が開く日の3週間前までに届くように」と、郵送は必着が多いことを書く。
2. **電話番号**：陳情書に電話番号の欄（または別紙）を設ける。書いていないと審査しない議会がある（習志野市）。
3. **意見書の案**：国への意見書を求める陳情には、意見書の案（提出先つき）を別紙で付けられるようにする。浦安市・今治市・習志野市・千葉市が求めている。
4. **1件1事項**：今の「1通ずつ別の紙」は合っている。所管の委員会が違う内容をまとめないことも書く。
5. **市外から出すとき**：在勤・在学などのつながりがあれば本文に書くよう案内する。
6. **公開**：名前と住所は原則公開されることを、出す前に伝える。
7. **意見陳述**：希望するなら提出のときに申し出ることを書く。
8. **要望書（首長あて）**：回答がほしければ「回答を希望します」と書き、連絡先を書く。入力フォームは字数の制限があることがあるので、長い要望書は郵送・FAXで出す。国の制度に関わる内容は首長あてには入れない。
