# 提出までの障害の TODO

最終更新：2026-11-12

LP にアクセスしてから実際に陳情を出すまでの障害を、2026-11-12 にサイト全体を見直して洗い出した。そのうち済んだものと、あとでやるものをまとめる。

## 済み
- 個人情報の扱いの説明を、FAQ と作成画面でそろえた。住所・氏名を「覚えておく」は、初めはチェックなしにした（#261）。
- 費用・切手の目安を、クリアファイルを全部で1枚とする前提にそろえた。特定記録の加算は210円に直した（#261）。
- 「1通にまとめる」と「項目ごとに1件ずつ」の食い違い、押印の書き方、about の「採択・不採択が出る」を直した（#261）。
- 作成画面の「今やること」に、議会事務局へ電話で聞くことを4つ（審査の扱い・締切・公開の範囲・書式と議長名）まとめた（#262）。

## あとでやること
どれも議会ごとのデータを集める必要があり、手間が大きい。

### 議長の氏名
- [ ] いまは利用者が自分で調べて入れるか、手書きにしている。
- [ ] 議会ごとの議長の氏名を集めて、宛名に自動で入れる。郵送の扱いと同じように、人口の多い順に進める。
- [ ] 議長は選挙や交代で変わる。確かめた日を残し、古くなったら「確かめてください」と出す。

### 締切（定例会の日程）
- [ ] いまは「定例会の1〜2週間前が多い」と書いているだけ。
- [ ] 議会ごとに、陳情の締切の決め方（開会の何日前か）と、案内ページの URL を集める。
- [ ] 作成画面で、次の定例会と締切の目安を出す。

### 紙と手書きの署名が前提
- [ ] いまは印刷・署名・郵送か持参が前提で、サイトの中では出し終わらない。
- [ ] 電子申請（フォーム・メール）で陳情を受け付ける議会を集めて、作成画面からその窓口へ直接案内する。
- [ ] 電子申請のときに、文面をそのまま貼れる形（本文だけのテキスト）で渡す。

### そのほか
- [ ] 住所・氏名の公開をどこまでにしてもらえるか（町名までなど）を議会ごとに集め、議会を選んだときに出す。
- [ ] 陳情書1件が実際に何枚になるかを、作ったPDFで確かめる。費用の表は「1件3枚ほど」の前提で書いている。
- [ ] postage.js は、どの画面からも呼ばれていない。作成画面で議会ごとの枚数から切手の目安を出すのに使うか、消すかを決める。
