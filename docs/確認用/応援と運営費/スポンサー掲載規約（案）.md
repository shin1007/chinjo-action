# スポンサー掲載規約（案）

2026-11-15 の下書き。サイトには出していない。窓口（決済の方法）と、下の「決めること」が決まるまで、募集は始めない。弁護士・行政書士の募集は、規程の原文を読んでから（[応援の受け付けのTODO](応援の受け付けのTODO.md) の調べた結果）。

## 目的（ページに書く文）
陳情アクションは個人が運営しています。生成AIの利用料金は、いまは運営者が自費で払っています。この費用をまかなうために、法人・団体の方からスポンサーを受け付けます。

## 約束（いちばん上に書く）
1. **スポンサーになっても、陳情の内容・文面・参考資料は変わりません。** 内容は、一次資料で確かめられるかどうかだけで決めます。スポンサーは内容の修正・追加・削除を求められません。
2. **掲載は広告・応援の表示であり、サイトがその団体を推薦・保証するものではありません。** 利用者は、掲載された団体に相談・依頼する義務も、しないことの不利益もありません。
3. **このサイトは、掲載された団体を利用者に紹介して手数料を受け取ることはありません。** 料金は、定額の掲載料だけです。

## 掲載できる団体
- 法人、事業者、市民団体、NPO、自治会など。個人の事業として営業している方は、事業のためにお申し込みください。
- 掲載の可否は運営者が決めます。断る場合も、理由は申し上げないことがあります。

## 掲載しない団体・内容（案）
- 政党・政治団体・候補者・公職にある者の個人の名義（特定の政党・候補者の支持につながるため）
- 陳情の対象とされている事業・制度と、強い利害関係がある事業者（利益相反のおそれ）
- 反社会的勢力、法令に違反するおそれのある事業
- 個人を誹謗するもの、差別をあおるもの、事実と異なる内容、誇大な表現
- 弁護士・行政書士など（当面は受け付けない。広告・紹介料の規程を確かめてから、別の条件で検討する）
- 陳情書などの書類の作成を、このサイトを通して請け負うと誤解させる内容

## 料金・期間（案。決めること）
- 月額5,000円〜（税込・税別は未決）。期間は1か月ごとの更新。解約は、次の更新の前までに連絡すれば、次の月から外す。日割りでの返金はしない（要確認）。
- 掲載の形：名前とリンク（5,000円）、バナー（金額は未決）。リンク先と画像は運営者が確認してから載せる。
- 掲載する場所：/support の「スポンサー」の欄。トップやフッターには出さない（陳情の画面に広告が混ざらないようにするため）。

## 申し込みから掲載まで（案）
1. メールで、団体名・担当の連絡先・リンク先・希望の掲載の形を送る。
2. 運営者が、掲載の可否と、上の基準への該当を確かめる。リンク先の内容も見る。
3. 受け付けたら、支払いの方法を案内する（窓口が決まるまで募集しない）。
4. 入金を確認してから掲載する。ロゴ画像は、運営者が表示を確かめてから公開する。

## 掲載の取り下げ
次のときは、予告なく掲載を外し、残りの期間の掲載料を返す。
- リンク先が変わって、上の基準に当たるようになったとき
- 団体が、法令や、このサイトの約束に反したことがわかったとき
- スポンサーが、陳情の内容を変えるよう求めたとき

## 個人情報
- 受け取るのは、団体の連絡先（担当者名・メールアドレス）だけ。掲載と連絡の目的以外には使わない。サイトの公開部分には、団体名とリンク先だけを出す。
- 個人情報の取り扱いの法令の確認は、まだ。確かめるまでは、連絡先はメールの履歴の中にだけ残し、データベースには入れない。
