# docs の分け方

- [確認用/](確認用/)：オーナーが読む・確かめる・ほかの人や AI に渡すもの
  - [見本/](確認用/見本/)：サイトが作る陳情書の文面（参考資料まで）と出し方メモ。`node scripts/samples.js` で作り直す
  - [一次資料に当たれていない資料.md](確認用/一次資料に当たれていない資料.md)：原文を確かめられなかった資料・サイトに入れなかった調査の記録
  - [ほかのAIへの依頼/](確認用/ほかのAIへの依頼/)：Grok・Gemini に貼る依頼文と、次に投げてほしい順番
  - [外部レビュー/](確認用/外部レビュー/)：外部の AI に渡すテーマごとの資料（`node scripts/review-pack.js`）
  - TODO（提出までの障害・応援の受け付け・要望と陳情の検索）、Xの投稿案、電話で確かめたい議会の一覧など
- [作業メモ/](作業メモ/)：AI が作業するときに読む設計・方針・訳（陳情の基本方針、データ構造、郵送の扱いの設計、英語の資料の訳）
