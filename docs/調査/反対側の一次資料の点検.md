# 反対側の一次資料の点検

2026-11-22 に始めた。ユーザーの決定：反対側・利害の異なる立場の主張を、一次資料で確かめて、文面の「理由」がそれを想定しているか点検する。

## 最初に分かったこと

- 6テーマの参考資料のリンク先は、法令（e-Gov）・官公庁・国会・裁判所・DOI（論文）がほとんど。一次資料中心という点では偏っていない（`site/themes/*` のリンクのドメインを数えた）。
- 偏りが出やすいのは、反対側の主張の置き場所。基本方針（[陳情の基本方針](../設計/陳情の基本方針.md)の5）に反対側の論点と応え方の表があるが、出典に報道（s-newscommons）が混じる。文面側（`site/themes/*/reasons.js`）で反対側に応えているのは、いまのところ「DV・虐待のあるケースの除外」の趣旨が中心。
- /about の可決事例は「親子ネットのまとめ」に頼っている。議会の会議録・意見書の原文で確かめ直す余地がある。
