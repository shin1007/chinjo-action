## 利用者から届いた URL の反映のしかた

/letter の「調査中」の横のリンクから、/feedback（種類は「根拠になる資料を知らせたい」、対象は「○○議会の議員名簿の公式ページ」）に届く。届いたら次の順で。
1. URL を開き、公式（lg.jp・自治体のドメイン）で、いまの任期の議員の名前が載っているかを確かめる。確かめられなければ足さない。
2. `site/data/roster.json` の該当の議会（`都道府県/市区町村`）に `{"url":…,"title":…,"found_at":日付}` を入れる。
3. `node scripts/roster-names.js --only <都道府県/市区町村>` で名前を抜き出す（抜き出せなければ「調査中」の表示のまま）。
4. `docs/調査/議員名簿のページが見つからない議会.md` と、このファイルの該当の行を消し、`npm run progress`（/coverage の「ほかの調査の進み具合」の数字を作り直す）を走らせ、/trouble の件数を直す。
