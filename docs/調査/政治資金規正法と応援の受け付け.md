# 政治資金規正法と、運営費の応援の受け付け（2026-11-23）

SNS の開設と運営費の応援の受け付けを始める前に、政治資金規正法の「政治団体」に当たるかを確かめようとした。**選挙管理委員会の答えは出た（2026-11-27、下の節）。当たるかは運営者が自分で判断することになった。2026-11-28 に条文を読み直した見立ては下の節。** 条文は読めたが、総務省の解釈（個人が運営するサイトの扱い）は読めていない。

## 読めたもの（一次資料）
e-Gov 法令検索のデータ（https://laws.e-gov.go.jp/api/1/lawdata/323AC1000000194 、2026-11-23 に取得。昭和23年法律第194号。附則に並ぶ改正法のうち最後は令和7年法律第41号で、令和8年1月1日施行。公式の最新の改正日までは確定できていない）：

- 第3条第1項第1号：「政治団体」とは、「政治上の主義若しくは施策を推進し、支持し、又はこれに反対することを本来の目的とする団体」（ほか2号・3号あり）。
- 第4条第4項：「政治活動に関する寄附」とは、「政治団体に対してされる寄附又は公職の候補者の政治活動（選挙運動を含む。）に関してされる寄附」。
- 第6条第1項：政治団体は、組織の日から七日以内に届け出る。第8条：届出の前は、政治活動のために寄附を受けることができない。
- 第21条の2：何人も、公職の候補者の政治活動（選挙運動を除く。）に関して、政治団体に対するものを除き、寄附（金銭等）をしてはならない。
- 第21条の3第3項・第22条第2項：個人が政治活動に関して寄附できる額の上限。

## 読んだ範囲でわかること
- 「政治団体」の定義は「団体」である。陳情アクションは、運営者個人が運営している（団体ではない）。
- ただし、個人が運営するサイトが「団体」に当たる場合があるか、運営者個人への応援が「政治活動に関する寄附」に当たるかは、条文だけでは決まらない。読んだ範囲に、個人が活動する場合の扱いの記述はなかった。

## 総務省の案内（2026-11-24 に読めた。文字コードを Shift_JIS にして読み直した）
- 「政治資金規正法のあらまし」（https://www.soumu.go.jp/main_content/000174716.pdf 、総務省自治行政局選挙部政治資金課。p.3）：「政治上の主義若しくは施策を推進し、支持し、又はこれに反対すること」などの活動を**本来の目的とする団体**、およびそれらを**主たる活動として組織的かつ継続的に行う団体**を、政治団体としている。
- 「なるほど！政治資金」（https://www.soumu.go.jp/senkyo/seiji_s/naruhodo01.html ）：政治団体は、収支報告書の提出と公表の対象。公職の候補者の政治活動に関する寄附は、政治団体への寄附なら認められる。
- **読んだ範囲の見立て**：定義は「団体」で、「組織的かつ継続的」が要る。個人が運営するサイトへの応援が当たるかは、この案内からは決まらない（個人の扱いの記述はない）。政策を提言するサイトなので、「政治上の施策を推進する」に当たりうるかは、窓口に聞くのが確実。
- 同じ総務省に「法令適用事前確認手続」（https://www.soumu.go.jp/menu_sinsei/hourei_tekiyou/index.html ）がある。この制度が、政治資金規正法の個別の相談に使えるかは、未確認（窓口で聞く）。

## 千葉県選挙管理委員会の回答（2026-11-27、メール）
- 政治団体に当たるか、そもそも活動主体が団体かは、実態によりそれぞれの者が判断するもので、選挙管理委員会では判断できない。
- 第4条第4項は「政治活動に関する寄附」を、政治団体または公職の候補者の政治活動に関してされる寄附と定義しているので、政治団体に当たらない場合は、同項の寄附とは見なされないと考える。
- 「寄附」は、金銭・物品その他の財産上の利益の供与または交付で、党費・会費その他債務の履行としてされるもの以外のもの（第4条第3項）。実態に即して判断を。
- 個別の事例の正式な見解を書面で出すことはしない。制度の概要は県選管の「政治団体の手引」（https://www.pref.chiba.lg.jp/senkan/seijidantai/teishutsu.html からリンク）を見るように。
- 手引の PDF（seijidantainotebiki.pdf、約9MB）は 2026-11-27 に取得したが、文字を取り出せなかった（画像か埋め込みの字形のため）。未読。

## 2026-11-28 の確認（条文の読み直しと Web 検索）
- e-Gov 法令API v2（https://laws.e-gov.go.jp/api/2/law_data/323AC1000000194 、令和8年1月1日施行の版）で、第3条第1項・第4条第3項・第4項・第21条の2を読み直した。上の節の要約と変わりはない。
  - 第3条第1項は、どの号も「団体」をいう。
  - 第4条第4項の「政治活動に関する寄附」は、政治団体への寄附か、公職の候補者の政治活動に関する寄附だけ。
  - 第21条の2が禁じているのは、公職の候補者（第3条第4項。候補者になろうとする者と公職にある者を含む）の政治活動に関する寄附。運営者は公職の候補者ではない。
- Web 検索では、総務省（https://www.soumu.go.jp/main_content/000174716.pdf ほか）と県の選挙管理委員会の手引き（熊本県・広島県・大阪府・埼玉県・長崎県の PDF）が見つかった。ただ、どれにも「個人が運営するサイトへの応援」をじかに扱った記述は見つからなかった（検索結果の要約で確かめた範囲。手引きの本文は全部は読んでいない）。
- ほかの AI（Gemini）にも聞いた。答えは「原則として対象外。使い道を運営費と明記するのがよい」で、条文の読み方と合っている。ただ、二次資料なので根拠にはしない。
- **見立て**：条文と千葉県選管の回答のとおり、運営者個人は「団体」ではない。公職の候補者でもない。使い道は運営費だけ。なので、政治団体への寄附にも、公職の候補者の政治活動に関する寄附にも当たらない、と運営者が判断できる材料はそろった。最終の判断は運営者がする（選管は判断しないと回答済み）。気をつけること：仲間と組織的・継続的に活動するようになると、第3条第1項第3号の「団体」に当たりうる。特定の候補者を推薦・支持するようになると、第2号に当たりうる。応援を、特定の議員・政党・候補者のために使わない。

## 決めたこと
- 2026-11-28 に Buy Me a Coffee で応援の受け付けを始めた（上の見立てのとおり、運営者個人・運営費だけ・候補者の推薦はしない）。使い道は「運営費（生成AIの利用料、根拠を原文で確かめるための有料の論文の購入）」と、サイトと Buy Me a Coffee のページの両方に書いた。
- それより前は、応援の受け付けは、確かめるまで始めないとしていた。
- サイトの各ページのフッターに「運営者個人が運営する（団体ではありません）」と明記した。
