# 手で開いてほしいページ

リンクは、目次やトップではなく、保存してほしいページそのものへの直リンクにする（2026-11-20 から）。直リンクが分からないものは、そう書く。

自動の取得（curl・スクリプト）では読めず、人がブラウザで開けば読める見込みのページの一覧（2026-11-19 にまとめた。同日に手で保存してもらって読めたものは消した。保存したファイルは 論文・一次資料・二次資料/手で保存（2026-11-19）/ にある）。元の記録は各ファイル（下の「出どころ」）にある。開いて読めたら、Chrome の「名前を付けて保存」で保存し、`node scripts/archive.js <URL> "<題名>" "<メモ>" --file <保存したファイル>` で登録するか、保存したファイルの場所を伝えてもらえれば、こちらで読んで反映する。読めたもの・読めなかったものは [ ] に印を付ける。
