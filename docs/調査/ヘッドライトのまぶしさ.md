# ヘッドライトのまぶしさ（下調べ）

2026-11-20 に調べた。ここに書くのは公開してよいことだけ。

**結果**：すでに「その他の陳情」に国への項目 `n_vehicle_light`（site/themes/sonota/asks-national.js）があったので、新しいテーマは作らず、そこに下の1（300件・オートレベリング）と2（相性の悪いバルブ）を足した。自治体への要望 `l_light_campaign`（交通安全の広報にライトの向きの点検とロービームへの切り替えを入れる）を新しく足した。出てくる場所は /sonota/make の「求める内容」。

## 一次資料で確かめたこと

### 1. オートレベリング（光の向きを自動で直す装置）の義務の拡大（国土交通省、令和6年9月20日）

- 報道発表 https://www.mlit.go.jp/report/press/jidosha10_hh_000311.html 、本文 https://www.mlit.go.jp/report/press/content/001763900.pdf 、別紙 https://www.mlit.go.jp/report/press/content/001763901.pdf （2026-11-20 に原文を確認）
- 後ろの席に人が乗ったり荷物を積んだりすると車の後ろが下がり、ライトが上を向いて「対向車のドライバー、特に高齢者ドライバーに眩しさを与えるリスク」がある。
- 2006年の新車から、光源の明るいライトの車にはオートレベリングの義務があった。それでも「ヘッドライトの眩しさにより、周囲の自動車等の発見が遅れ、事故に繋がったというケースが過去10年間（2012～2021年）で300件以上」。**この件数のもとのデータ（事故統計のどれか）は発表に書かれていない。未確認。**
- 改正：これまで「光源が 2,000lm 超の高輝度のすれ違い用前照灯」の車だけだった義務を、光源の明るさにかかわらず、必要な全ての自動車に広げる（二輪・大型特殊などは除く）。国連の協定規則第48号の改訂（WP29 第192回会合）に合わせたもの。告示は「道路運送車両の保安基準の細目を定める告示」（平成14年国土交通省告示第619号）。**条番号は告示本文で未確認。**
- 適用日：乗車定員10人以下の乗用車等は新型車 令和9年9月1日・継続生産車 令和12年9月1日。3.5t 超の貨物車と11人以上の乗用車は新型車 令和10年9月1日・継続生産車 令和13年9月1日。
- → 陳情の論点：**すでに走っている車（とくに義務の前の車）には及ばない。**

### 2. 車検のロービーム計測（自動車技術総合機構・軽自動車検査協会・国土交通省）

- 「車検時にはヘッドライトテスタを用いてロービームを計測します」（令和6年8月） https://www.naltec.go.jp/news/gtg5d20000000556-att/gtg5d20000000562.pdf （2026-11-20 に原文を確認）
  - 平成10年9月1日以降に製作された自動車は、車検でロービームが「照射光線が他の交通を妨げないこと」などを満たすかをヘッドライトテスタで検査している。
  - 不合格の車には「前照灯ユニットと相性の悪いバルブに交換した等により、光度が不足した状態や配光が崩れた状態のまま受検しているもの」が多いと書いている。→ **後付けのバルブ（LED を含む）で光の形が崩れる問題を、国も認めている。**
  - 光の向きは走行の振動などで「ズレていく」とも書いている。→ 車検と車検の間の点検の論点。
- 「カットオフラインが確認できない自動車などのロービーム計測について」（令和6年6月） https://www.naltec.go.jp/news/gtg5d200000005fp-att/gtg5d200000005gl.pdf ：令和6年8月1日から、境目（カットオフライン）が見えない車は最高光度点の位置で測る。最高光度点の光度は1灯 6,400cd 以上。
- 「前照灯検査（ロービーム計測）の合格割合を公表します」（令和8年9月） https://www.naltec.go.jp/news/hbh5ss0000001vtr-att/hbh5ss0000001vu7.pdf ：令和8年3〜8月の表に「99%：1％」などとある。**表の見出し（ロービーム計測：過渡期取扱い計測）の読み方が文字の取り出しでは確かめきれない。** 図を目で見て確かめる。
- 令和8年8月1日からの全車のロービーム計測への移行：近畿運輸局の「令和８年８月１日より、『ロービーム計測』に移行します」（令和8年5月） https://wwwtb.mlit.go.jp/kinki/content/000374454.pdf が、すでに n_vehicle_light の参考資料に入っている。

### 3. 英国運輸省が頼んだ調査（TRL PPR2069、2025年10月）

- TRL "Glare from vehicle lighting on UK roads"（PPR2069、Department for Transport 向け、2025年10月） https://www.trl.co.uk/uploads/trl/documents/PPR2069-Glare-from-road-vehicle-lighting.pdf （2026-11-20 に原文を確認）
- 方法：夜間に計測用の車で走り、まぶしさを感じたら観察者がボタンを押す路上の計測と、RAC のパネルでの英国の運転者 1,850人の調査。
- 調査（56〜57ページ ほか）：96% が「ほとんど」か「一部」のライトが明るすぎると感じ、97% が対向車のライトで「よく」か「ときどき」目がくらむと答えた。4% が夜の運転をやめ、29% が減らし、22% が減らしたいが減らせないと答えた（合わせて約55%）。
- 路上の計測（要旨 ii〜iii ページ）：明るさ（輝度）が高いほどまぶしさを感じやすく、40,000 cd/m² を超えると急に増える。SUV など大きい車や LED のライトとの関係は「tentative」（仮の示唆）で、「extreme caution」で扱うべきと書いている。上り坂・カーブなど道の形の影響も大きく、規制を強めても残るまぶしさがあるとしている。
- → 陳情で使えるのは「英国では運輸省が調査を頼み、運転者の大多数がまぶしさを問題と答えた」まで。**「LED が原因」とまでは言えない**（報告自身が慎重）。

## 項目の下書き（国への意見書を求める陳情）

1. 後付けのヘッドライト用バルブ（LED を含む）について、取り付けたあとも光の形（ロービームの境目）が崩れないことを確かめる仕組みと、販売の際の表示の基準を設けること。
2. すでに走っている車について、ロービームの光の向きを車検のあいだにも点検できるよう、点検の呼びかけと、街頭での検査を強めること。
3. ヘッドライトのまぶしさと事故の関係を国内で調べ、結果を公表すること（英国の調査のような、運転者への調査と路上の計測）。
4. 国連の基準づくり（WP29）で、まぶしさを減らす基準（光の強さの上限、車高の高い車のライトの位置など）を日本からも提案すること。

それぞれ、理由の根拠になる一次資料がまだ足りない点：1 は後付けバルブの扱いを定めた告示・通達、2 は街頭検査の件数、3 は国内の研究（交通安全環境研究所など）、4 は WP29 の照明の分科会（GRE）の議論。
