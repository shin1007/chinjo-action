# 議員の名簿を機械で読めなかった資料（手で確かめたいもの）

scripts/roster-names.js などで名前を取ろうとして、開けなかった・文字にできなかった資料の記録。
自動で書き出す一覧は 議員の名前を抜き出せなかった議会.md にある。ここには、手で調べた結果を書き足す。

## 2026-11-21

- 熊本市議会：議員の名簿のページが見つからない。市の公式サイト（https://www.city.kumamoto.jp/ ）の中に、議会のページへのリンクが見当たらない。https://www.city.kumamoto.jp/gikai/ は 404。
  - 検索で出てきた「議員の会派所属等一覧表」（令和6年10月1日現在）の PDF https://www.city.kumamoto.jp/kiji00357794/5_57794_413355_up_K7XDQ7SE.pdf は 404（消されている）。
- 葛飾区議会：議員の名簿のページが見つからない。区の公式サイト（https://www.city.katsushika.lg.jp/ ）の区政情報の中に、区議会のページへのリンクがない。
- 島根県議会：名簿は PDF（https://www.pref.shimane.lg.jp/gikai/gaido/meibo/ の「議員名別名簿」など）で、一部の名前しか文字にならない。
  - 選挙の記録の PDF https://www.pref.shimane.lg.jp/admin/commission/senkyo/shimane_senkyo/kiroku/kenngikiroku.data/R5kengi.pdf は、pdftotext でも PyMuPDF でも文字化けする（字体の文字の対応表が壊れている）。
  - 開票速報 https://www1.pref.shimane.lg.jp/contents/shichoson/2023tijikengi/ は読めるが、名前が選挙の書き方（「角　ともこ」）で、名簿の書き方（「角 智子」）と違うため、名簿で確かめる材料にならない。
- 船橋市議会：名簿のページ https://www.city.funabashi.lg.jp/assembly/004/001/p138768.html に、49人のうち約30人の名前しか文字で書かれていない。選挙結果（https://www.city.funabashi.lg.jp/shisei/senkyo/007/p114955.html ）と照らしても増えない。
- 八王子市・長崎市・尼崎市：選挙管理委員会の公式の選挙結果のページを検索で見つけられなかった（民間のまとめサイトしか出てこない）。
