## 確かめられなかったこと
- 「審査の前に、担当部署が事実確認や是正を始める」ことは、上のどの公式ページにも書かれていない。Grok の説明（実務上そうなることが多い）は一次資料が付いていないため、サイトには載せていない。
- 「配付・通知」は、行政が内容を知る機会があることまでを示す。是正の約束ではない。
- 神奈川県議会の「陳情書処理規程」、各議会の会議規則・委員会条例の原文は未確認。
- 次の手がかり：残りの議会（約1,630）の案内ページ、会議規則、陳情の処理規程。議会事務局への問い合わせ結果は `route: office_reply` で記録する。

## 国への意見書を求める陳情を分けて出す案（2026年11月21日）
- ガイドに「試す価値のある工夫・効果は未確認」として書いた。根拠は、鎌ケ谷市議会の案内（「市の事務に関係しない事項を願意とするもの（ただし、意見書提出を願意とするものは除く。）」は委員会で審査しない取扱いの例外）と、浜松市議会の案内（意見書を求める陳情だけ提出期限を設ける）。
- 「住民でなくても要望と同じ効果がある」は言えない。住民以外の陳情を配付だけにする議会は多い（`site/data/intake/chinjo.jsonl` の `nonresident_rule`）。

## 人口の多い順に1,241議会の案内ページを機械で調べた結果（2026年11月21日）
- 対象：site/data/intake/chinjo.jsonl で案内ページ（PDF 以外）の URL がある1,276議会のうち、取得できた1,241議会。取得できなかったのは35（503・時間切れなど）。
- 方法：「執行機関・執行部・庁内・担当部局・関係課・市長」などの語と「陳情」が同じ行にある文を機械で拾い、目で確かめた。
- 結果：提出の時点（採択の前）に、陳情の写しや文書表を執行機関・執行部・担当部局に配ると書いていた議会は、約40（下の表。上の表の議会を含む）。ほかに、採択後に市長等へ送付すると書く議会が約60。
- 注意：書いていない議会が「配らない」とは限らない（案内に書いていないだけのことがある）。語の拾い漏れもある。
- 横浜型（行政への要望の陳情は議長が市長等に回答を求める）：横浜市に加え、霧島市（<https://www.city-kirishima.jp/gikai/shise/shigikai/shikumi/segan-chinjo.html>）「それ以外の陳情（行政への要望に関する陳情等）は、議長が市長等の回答を求め、その旨を陳情者に通知します。」
- 配らない例：能美市（<https://www.city.nomi.lg.jp/docs/216.html>）「なお、協議した結果について、市長や関係機関への送付や陳情者への通知は行いません。」
- 結果を市長に送る例：花巻市（<https://www.city.hanamaki.iwate.jp/shigikai/1004078.html>）「請願・陳情の審査結果は、提出者に文書で通知するとともに、市政に関する請願・陳情については、その結果を市長に送付します。」

## 会議録での実例探し（2026年11月21日・Web検索のみ）
- 「陳情が提出されました」「陳情を受けて質問」などの語でWeb検索（標準・拡張）を3回。会議録の実例は見つからなかった。出てきたのは、横浜市・北九州市・京都市などの取扱いの案内、京都市の議事日程（一般質問の前に「陳情の回付」）など。
- 会議録の検索システム（ssp.kaigiroku.net、gijiroku.com、dbsr.jp、各市独自など）は議会ごとに別。全文検索を自動で回すには、システムごとの調査が要る。未着手。
- 案内ページのURLがない511議会（`node scripts/intake.js todo page`）は、`scripts/intake-find.js` で一度探して見つからなかったもの（`docs/調査/陳情の案内ページが見つからない議会.md`）。ブラウザでの目視が要る。

## 会議録での実例（2026年11月21日）
- 方法：南国市・安芸市の会議録検索（`giji_result.php` を GET で検索。区分は一般質問、語は「陳情」）で出た89件の本文から、「陳情書が出された／提出された／陳情を受けた」を述べる段落を機械で拾い、目で確かめた。四万十町は同じ方式の検索で0件（仕組みが違う可能性）。
- 例（南国市議会 令和元年第407回定例会、2019年6月。市内の民間保育所の陳情書）：
  - 質問：https://www.city.nankoku.lg.jp/gijiroku/giji_dtl.php?hdnKatugi=1000&hdnID=1237 「今回の議会に市内の民営保育所より、保育園で働く保育士に見合った処遇の実現を求め、運営の補助拡充についての陳情書が提出されています。」
  - 質問：同 hdnID=1244（4日目）、hdnID=1247（4日目）。複数の議員が同じ陳情書に触れている。
  - 答弁：同 hdnID=1245「これは平成30年４月現在、陳情書にありました数字になっております。」（担当課長の答弁）
- ほかの例：南国市 2017年6月（hdnID=1011、文化施設の整備の陳情書）、2010年9月（hdnID=351、通信基地の貸付けの解除の陳情書。「全議員に届けられておりますし、総務常任委員会に付託」）、2023年12月（hdnID=1737、課長が陳情の署名を「重く受け止め」と答弁）。
- できないこと：これは「陳情が議員の質問につながりうる」実例で、割合や、すべての議会での傾向は示さない。陳情が行政の是正につながったかも、会議録の範囲では確かめていない。議員の名前はサイトには載せない。
- 次の手がかり：ほかの会議録検索システム（ssp.kaigiroku.net、gijiroku.com、dbsr.jp など）で同じ検索をする。
