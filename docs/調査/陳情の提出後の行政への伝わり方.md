# 陳情を出したあと、行政にどう伝わるか（2026年11月21日に確認）

利用者向けの出どころ：各テーマの `/<テーマ>/guide` の「3. 提出までの流れ」の下。未確認の点は `/trouble` の「調査を手伝ってほしいこと」。

| 議会 | 公式ページ | 書いてあること（原文の要点） |
|---|---|---|
| 静岡市議会 | https://www.city.shizuoka.lg.jp/gikai/s006687.html | 委員会での審査の流れは「陳情者の趣旨説明→質疑→行政担当者の説明→質疑→取扱いについての協議→採決」。陳情は委員会限りで結論が出る。郵送・電子申請の陳情は原則、議長供覧。 |
| 鎌ケ谷市議会 | https://www.city.kamagaya.chiba.jp/gikai/seigan-chinjyou.html | 「請願書、陳情書が採択されると、議会はその旨を市長に送付します」。原本の写しを市議会議員、市執行部に配付する。郵送の陳情は写しを全議員に配るのみ。 |
| 神奈川県議会 | https://www.pref.kanagawa.jp/gikai/p80218.html | 「陳情は請願と異なり、関係執行機関へは送付されませんが、陳情に関係する執行機関は、陳情内容に留意し、仕事を進めることになります」。 |

## 確かめられなかったこと
- 「審査の前に、担当部署が事実確認や是正を始める」ことは、上の3つの公式ページのどれにも書かれていない。ほかの議会の公式ページも未確認。Grok の説明（実務上そうなることが多い）は一次資料が付いていないため、サイトには載せていない。
- 次の手がかり：ほかの議会の「請願・陳情の取扱い」「陳情書処理規程」「会議規則」で、陳情を執行機関へ送付・通知するか、事前に所管へ共有するかを探す。議会事務局への問い合わせ結果は `route: office_reply` で記録する。
