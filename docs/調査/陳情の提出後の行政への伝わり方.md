# 陳情を出したあと、行政にどう伝わるか（2026年11月21日に確認）

利用者向けの出どころ：各テーマの `/<テーマ>/guide` の「3. 提出までの流れ」の下。未確認の点は `/trouble` の「調査を手伝ってほしいこと」。
方法：`site/data/intake/chinjo.jsonl` の page_url のうち人口の多い60議会（PDF を除く）を取得し（続けて61〜160位も同じ方法で取得。この2回で160議会）、「執行機関・執行部・関係部課・理事者」などの語と「陳情・請願」が同じ行にあるものを拾った。取得できなかったのは岡山県（503）、大阪府吹田市・八尾市（503）、埼玉県草加市（時間切れ）。拾えたのは下の表の議会。ほかの議会は、案内ページに書かれていないか、この語で拾えていない（書いていないことの証明ではない）。

## 確かめられなかったこと
- 「審査の前に、担当部署が事実確認や是正を始める」ことは、上のどの公式ページにも書かれていない。Grok の説明（実務上そうなることが多い）は一次資料が付いていないため、サイトには載せていない。
- 「配付・通知」は、行政が内容を知る機会があることまでを示す。是正の約束ではない。
- 神奈川県議会の「陳情書処理規程」、各議会の会議規則・委員会条例の原文は未確認。
