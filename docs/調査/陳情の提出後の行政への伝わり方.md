# 陳情を出したあと、行政にどう伝わるか（2026年11月21日に確認）

利用者向けの出どころ：各テーマの `/<テーマ>/guide` の「3. 提出までの流れ」の下。未確認の点は `/trouble` の「調査を手伝ってほしいこと」。
方法：`site/data/intake/chinjo.jsonl` の page_url のうち人口の多い60議会（PDF を除く）を取得し、「執行機関・執行部・関係部課・理事者」などの語と「陳情・請願」が同じ行にあるものを拾った。60のうち503（岡山県）は取得できず。拾えたのは下の表の議会。ほかの議会は、案内ページに書かれていないか、この語で拾えていない（書いていないことの証明ではない）。

| 議会 | 公式ページ | 陳情について書いてあること（原文の要点） |
|---|---|---|
| 千葉県議会 | https://www.pref.chiba.lg.jp/gikai/giji/aramashi/seigan.html | 「陳情書は、写しを議員や関係執行機関へ配付します」「写しを各議員に配付するとともに、知事やその他の関係執行機関にその内容を通知します」 |
| 埼玉県議会 | https://www.pref.saitama.lg.jp/e1601/gikai-seigan.html | 「陳情一覧表は、議案および請願の委員会付託日に各議員、執行機関等に配布します」 |
| 佐賀県議会 | https://www.pref.saga.lg.jp/gikai/kiji0034772/index.html | 陳情文書表を全議員、県執行部、報道関係者へ配付 |
| 愛知県議会 | http://www.pref.aichi.jp/site/gikai/seigan-chinjo.html | 陳情者の個人情報は「陳情内容を議員及び執行機関に周知するために利用」 |
| 沖縄県議会 | https://www.pref.okinawa.lg.jp/kensei/gikai/1024937/1017077.html | 請願・陳情文書表を議員及び執行機関に送付。「執行機関から請願（陳情）の要旨や処理概要の説明を聞き、質問などを通じて審査」。採択された請願（陳情）で処置が必要なものは知事等に送付し報告を求める（地方自治法第125条） |
| 大分県議会 | https://www.pref.oita.jp/site/gikai/oshirase-seiganchinjou.html | 「陳情は、所管委員会へ回付され、執行部の意見を聴取し…ただし、内容によっては議長への回付にとどめる場合があります」 |
| 静岡市議会 | https://www.city.shizuoka.lg.jp/gikai/s006687.html | 委員会の流れに「行政担当者の説明」。郵送・電子申請の陳情は原則、議長供覧 |
| 鎌ケ谷市議会 | https://www.city.kamagaya.chiba.jp/gikai/seigan-chinjyou.html | 原本の写しを市議会議員、市執行部に配付。採択されると議会が市長に送付。郵送の陳情は写しを全議員に配布のみ |
| 浜松市議会 | https://www.city.hamamatsu.shizuoka.jp/gikai/seigan.html | 「採択した陳情は、請願と同様に市長等の執行機関に送付されます」 |
| 名古屋市会 | https://www.city.nagoya.jp/shikai/bouchou/1031732.html | 請願に適合しない陳情は議長限り。委員会が採択した陳情のうち執行機関で処理することが適当なものは、委員長が口頭で執行機関に要望 |
| 神奈川県議会 | https://www.pref.kanagawa.jp/gikai/p80218.html | 陳情は執行機関へ送付されないが、「関係執行機関は、陳情内容に留意し、仕事を進める」 |

## 確かめられなかったこと
- 「審査の前に、担当部署が事実確認や是正を始める」ことは、上のどの公式ページにも書かれていない。Grok の説明（実務上そうなることが多い）は一次資料が付いていないため、サイトには載せていない。
- 「配付・通知」は、行政が内容を知る機会があることまでを示す。是正の約束ではない。
- 神奈川県議会の「陳情書処理規程」、各議会の会議規則・委員会条例の原文は未確認。
- 次の手がかり：残りの議会（約1,700）の案内ページ、会議規則、陳情の処理規程。議会事務局への問い合わせ結果は `route: office_reply` で記録する。
