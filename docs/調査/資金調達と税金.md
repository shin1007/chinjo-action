# 資金調達の方法と、税金の支払いで必要なこと（2026-11-23）

運営費（生成AIの利用料など）の応援や、SNS の収益を受け取るときに、税金でどんな行動が要るか。国税庁の公式ページ（令和8年4月1日現在法令等）で確かめたことと、確かめられていないことを分ける。**個人の事情（本業が給与か、ほかの所得があるか）によって変わるので、運営者の事情に当てはめた結論は出していない。** 当てはめるときは、税務署か税理士に確かめる。

## 確かめられたこと（一次資料）
| 事柄 | 内容（原文の引用） | 出典 |
|---|---|---|
| 副収入の申告（給与所得者） | 「給与所得以外に副収入等によって20万円を超える所得を得ている場合には、確定申告をすれば税金が還付される人を除いて、確定申告が必要となります」。給与の支払者が1か所で年末調整を受けている人の場合。「所得」は収入から必要経費を引いた額 | [No.1906](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1906.htm) 、[No.1900](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm) |
| 雑所得（業務） | 「業務に係るものとは、副業に係る収入のうち営利を目的とした継続的なものをいいます。」前々年分の収入金額が300万円を超えると現金預金取引等関係書類の保存が要る。1,000万円を超えると確定申告書に収支の内訳書などの添付が要る | [No.1500](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1500.htm) |
| 必要経費 | 「収入を得るために直接必要な売上原価や販売費、管理費その他費用」。家事上の経費は必要経費にならない。業務の部分を明らかに区分できれば、その部分は必要経費になる | [No.1350](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1350.htm) |
| 贈与税 | 「個人から贈与により財産を取得したときにかかる」。法人からの贈与は所得税。1年間の合計が110万円以下なら申告は不要。申告は翌年2月1日〜3月15日 | [No.4402](https://www.nta.go.jp/taxes/shiraberu/taxanswer/zoyo/4402.htm) 、[No.4408](https://www.nta.go.jp/taxes/shiraberu/taxanswer/zoyo/4408.htm) |
| 消費税の納税義務 | 「課税売上高が1,000万円以下である場合には、原則として、納税義務が免除」（個人は前々年が基準期間）。ただし適格請求書発行事業者（インボイス）の登録をすると免除されない。前年1〜6月の課税売上高が1,000万円を超えても免除されない。「事業を行っていない給与所得者などは消費税の納税義務者にはなりません」 | [No.6501](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6501.htm) 、[No.6125](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6125.htm) |
| 確定申告の期間 | 翌年2月16日〜3月15日（申告と納付の期限は3月15日） | [No.2020](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2020.htm) |

### 国税庁の機関（税務大学校）の研究者の論文（国税庁の公式見解ではない）
税務大学校論叢第100号（令和2年6月）「シェアリングエコノミーと消費税」（[PDF](https://www.nta.go.jp/about/organization/ntc/kenkyu/ronsou/100/04/04.pdf) 。本文は PDF から取り出して読んだ。冒頭に、意見にわたる部分は筆者の個人的見解である旨の断りがある）：
- 寄付型のクラウドファンディング：「資金調達という行為と支援者からの寄付（金銭）の間に対価性が認められない場合には、対価を得て行われていないことから消費税法上の『事業』とは認められない」。資金調達者が個人で、提供が個人からなら贈与税、法人からなら所得税（基礎控除額を超えた分が課税対象）。
- 購入型（リターンあり）：「対価を得て反復、継続、独立して行われる限り、金額の多寡にかかわらず消費税法上の事業に該当する」。原則、消費税の課税取引。
- 論文が扱うのはクラウドファンディングで、**「陳情アクションへの見返りのない応援」にそのまま当てはまるとは限らない。**

## 確かめられていないこと
- 見返りのない応援金を、個人の運営者が継続して受け取るとき、**贈与税（受け取る側）になるのか、所得税の雑所得になるのか。** 国税庁の No.4402 の Q&A（[4402_qa](https://www.nta.go.jp/taxes/shiraberu/taxanswer/zoyo/4402_qa.htm)）は文字化けで読めなかった。
- 事業所得と雑所得の区分の考え方（国税庁の該当ページは見つけられず、読めなかった）。
- 住民税の申告（所得税の確定申告が不要でも、住民税の申告は別に要る場合がある。国税庁のページには記述がなかった。お住まいの市区町村に確かめる）。
- X・note・応援サイトからの収入の源泉徴収・支払調書の扱い。
- 雑所得の赤字（応援より運営費が多いとき）を、ほかの所得と相殺できるか（私の理解では相殺できないが、一次資料では確かめていない）。
- 政治資金規正法に当たるか（[記録](政治資金規正法と応援の受け付け.md)）。

## 必要な行動（上から順に）
1. **運営者の収入の種類を確かめる**（給与のみ／個人事業／そのほか）。20万円の基準や贈与税の扱いが変わる。
2. **記録を付ける**：収入（応援・SNS・そのほか）と、運営費（Claude の利用料、ドメイン、Vercel、Supabase など）を、月ごとに。領収書・利用明細は保存する（雑所得で前々年の収入が300万円を超えると、保存が決まりになる）。
3. **応援の税の扱いを、税務署に聞く**：次の質問文を使う。
   「個人が運営する政策提言サイトの運営費として、見返りのない応援金を、オンラインの決済サービス経由で複数の個人から継続的に受け取ります。受け取る側の所得税・贈与税の扱い、確定申告が必要になる金額、必要経費にできる費用（生成AIの利用料など）を教えてください。」
4. **年間の所得が20万円を超えそうなら**、翌年2月16日〜3月15日に確定申告（給与所得者の場合）。超えなくても住民税の申告が要るかを、市区町村に聞く。
5. **消費税**：見返りのない応援は、対価がなければ消費税の対象外（論文の考え方）。note の有料記事のように、対価のある販売をする場合は課税売上になるが、前々年の課税売上高が1,000万円以下なら免除。インボイスの登録は、必要が出るまでしない。
6. **特定商取引法の表記**（`/tokushoho`）を、受け付ける方法に合わせて直す。
7. **政治資金規正法**（SNS運営の TODO の 1・2）の確認が済むまで、応援の窓口は開けない。
