## 探し方のメモ

- 結果の一覧を HTML で出している議会は、curl で取ってきて、テーマの言葉と「採択」を含む行を拾うと速い（中野区・目黒区・那覇市・うるま市・船橋市・鹿児島市・山梨県・神奈川県・千葉市・大田区を当たった）。
- 同じ団体が同じ文面の陳情を多くの議会に出すことがあるので、採択例が1つ見つかったら、件名でほかの議会を探すとよい。

## 2回目（2026-11-20）：90議会の結果一覧を機械でたどった

- 対象：東京23区、政令市20、47都道府県議会。site/data/sites.js の陳情の案内ページから、「請願・陳情」「結果」を含むリンクを2段までたどり（1議会70ページまで、合計904ページ）、PDFも文字にして、テーマの言葉と結果の「採択」を含む行を拾った。
- 結果：新しい採択例は0件。拾えたのは宮城県議会の平成22年の件名1件だけ（テーマ外）。
- 目黒区議会の令和8年第2回定例会の議決結果のページでも、陳情8第26号・第27号が採択と確かめた（https://www.city.meguro.tokyo.jp/kugikai/kusei/kugikai/8-2teirei-giketukeka.html）。
- 台東区議会：外国人の扶養控除の見直し（陳情27-22、平成27年）と年金の脱退一時金の是正（陳情5-19、令和6年）は、どちらも不採択。
- 江戸川区議会：「別居・離婚後の児童虐待等を防止する運用・法整備を求める陳情」（Se616_025chinnjyou.pdf）は文面だけ見つかり、結果は未確認。
- 限界：結果を画像のPDFや会議録検索システム（VOICES など）でしか出していない議会は、この方法では読めない。とくに市町村議会（約1,700）はほとんど当たれていない。

## 自動で探すスクリプト

`npm run adopted`（= `python scripts/adopted-scan.py`、要 `pip install pypdf`）。全国の議会の陳情の案内ページ（site/data/sites.js）から結果のページを3段までたどり、HTML と PDF の文字を「陳情第〇号」などの番号ごとに区切って、テーマの言葉と結果の「採択」が同じ件に入っているものを候補にする。目黒区議会・中野区議会の例を拾えることを確かめた。
- 候補：scripts/.intake-cache/adopted/candidates.tsv（Git に入れない）。終わった議会は done.json に残り、止めても続きから。
- 都道府県を絞る：`python scripts/adopted-scan.py 東京都 大阪府`。やり直す：`--again`。
- 候補はそのまま載せない。公式の資料を開いて、陳情か（請願・議員提出でないか）、結果、番号、日付を確かめてから、templates/parts/theme/<テーマ>-top.html に書き、`node scripts/pages.js`。
