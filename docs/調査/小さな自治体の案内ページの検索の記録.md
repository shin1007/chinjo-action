2026-11-23。陳情の案内ページが見つかっていない511議会（`docs/調査/陳情の案内ページが見つからない議会.md`）のうち、人口の少ない順に6議会を、検索（「〇〇議会 請願 陳情 提出方法」）で探した。

- 6議会とも、請願・陳情の出し方を書いた公式ページは見つからなかった。検索に出たのはほかの自治体のページで、根拠にはしない。
- 公式サイトのリンクをたどる自動の探索（`scripts/intake-find.js`）でも、511議会のうち見つかったのは0件（2026-11-23。プロキシ経由で再実行）。
- 人口が数百〜数千人の町村は、議会の請願・陳情の案内を公式サイトに載せていないことが多いと見られる（推測。サイトを1つずつ見て確かめたわけではない）。ページを探しても出てこない状態が、実態に近い。

## 方針

- 探索は続けても増えにくい。小さな議会は、議会事務局に直接聞くのが確実。
- `/coverage` の一覧に、事務局・担当課に聞く文をコピーするボタンを足した（2026-11-23）。聞いた結果は /kakunin から送ってもらい、運営が `route: "office_reply"` と日付だけを記録する。
- 個人の自治体の公式サイトで、トップから議会のページをたどれば見つかるものがあるかもしれない。ブラウザで探せる人は、/coverage の「知らせる」から URL を送ってほしい。
