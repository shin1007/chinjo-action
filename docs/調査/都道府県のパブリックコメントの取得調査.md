# 都道府県のパブリックコメントのページの取得調査

2026-11-22 に、`site/data/intake/yobo.jsonl` の47都道府県の `pubcom_url`（意見募集の一覧ページ）を機械で開き、募集中の案件を機械で読めるかを調べた。目的は [抜けている視点のTODO](../TODO/抜けている視点のTODO.md) の6（パブリックコメント）。

## 結果

- 開けたのは47のうち45（福井県・愛媛県は1回目に接続が切れ、再試行で開けた）。
- 開けなかったのは2：奈良県、香川県（「Connection reset by peer」。再試行でも同じ。サイトが自動の取得を拒んでいる可能性があるが、理由は未確認。取得を避ける工夫（ブラウザを装うなど）はしていない）。
- 47都道府県に共通の形式（RSS・API）はない。国（e-Gov）のような一括の RSS に当たるものは見つからなかった。
- ページ内に RSS への参照があったのは青森県（サイト全体の RSS）・高知県（index.rss）・茨城県・富山県・鹿児島県の5県。茨城・富山・鹿児島は名前から緊急情報の RSS と見え、意見募集のものではないと思われる（中身は確かめていない）。
- 一覧ページの HTML の作りは県ごとに違う。「募集中」と書いてある県（青森・群馬・埼玉・山梨・大阪・熊本など）と、案件のリンクだけが並ぶ県がある。締切の日付を同じ形で取り出すには、県ごとの読み取りの処理が要る。

## 判断

- 一覧のリンクを集めて「募集中」として出すと、募集が終わった案件を含むおそれがある。募集中かどうかを確かめられないものを「いま募集中」と出さないほうがよい（このサイトの方針：確かめられないことは書かない）。
- 案：県ごとの読み取りは大きな作業なので、まず、テーマに近い案件が出やすい県から数県だけ作り、ほかの県は一覧のページへのリンクのままにする。人口の多い都道府県から始める。
