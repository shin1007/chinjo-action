# 一次資料に当たれていない資料

陳情の文面に使う前に原文を確かめたいが、まだ確かめられていない資料の一覧。確かめたら、この一覧から削除する。

裁判所の判例は新しいURL（`https://www.courts.go.jp/hanrei/{番号}/detail2/index.html`）になっている。検索は `https://www.courts.go.jp/hanrei/search1/index.html?filter[jikenGengo]=平成&filter[jikenYear]=..&filter[jikenNumber]=..#searched` を Chrome で開く（curl では弾かれる）。

報道機関・個人のサイトは消えることがあるので、使ったら `node scripts/archive.js <URL> "<題名>"` で保存する。本文は sources/archive/（Git に入れない）に、URL・取得日時・SHA-256 は data/archive-index.json に残る。

## 取れなかった理由の区分

各項目の頭に、当たれなかった理由を付ける。

- 【BOT制限】サイトは動いているが、自動の取得（curl・スクリプト）を拒んでいる（403、空の応答、確認画面）。Chrome で人が開けば読める見込み。下の「BOT制限で取れなかったもの」にまとめた。
- 【サイトダウン】サイト自体が止まっている（メンテナンス中など）。人が開いても読めない。時間をおいて開き直す。
- 【その他】アクセスはできたが、資料が見つからない・404・載っていない・読み取れない・まだ試していない。

判定の根拠：403 や空の応答が返ったものを BOT制限とした。同じ URL をブラウザの名乗りで開き直して確かめることは、ボット対策をすり抜ける操作にあたるのでしていない。ブラウザで開いて読めなかったときは、区分を直す。

## BOT制限で取れなかったもの

Chrome で開いて「名前を付けて保存」し、`node scripts/archive.js <URL> "<題名>" "<メモ>" --file <保存したファイル>` で登録すれば使える。

- 【BOT制限】裁判所の裁判例検索（https://www.courts.go.jp/hanrei/search1/index.html）：curl では弾かれる。Chrome で開く（上の検索の URL の形を使う）。→具体的に何の裁判例かわからず、保留した。

- 【BOT制限】国連 OHCHR（https://www.ohchr.org/）：2026-11-12 に 403。日本が個人通報制度を受け入れているかを確かめられず、相談・救済窓口（common-actions.js）から「OHCHR 通報手続」を外したままにした。外務省の人権条約のページでも確かめられる。
