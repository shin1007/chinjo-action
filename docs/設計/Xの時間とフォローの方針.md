# X の投稿の時間・頻度の確かめ方と、フォローの方針

> X の運用全体は [Xの運用方法](Xの運用方法.md) にまとめた。この文書は、時間・頻度・フォローの詳細。

2026-11-23。出典は検索結果の要約と運用会社・ブログの記事（二次資料）。X の仕様書・公式の統計では確かめていない。**最も信頼できるのは、このアカウント自身のアナリティクス**なので、下の「試し方」で、自分の数字を取る。

## 1. 頻度と、インプレッションが鈍る心配について
- 心配は、もっともです。投稿を増やすと、1本あたりの表示が下がる可能性はある（二次資料に、投稿直後1時間の反応を重視する、という解説がある。公式には確かめていない）。反応の弱い投稿が多いと、見られにくくなる、と考えておく。
- そこで、**「多く出す」より「確かめながら出す」**。最初の4週間は、頻度を2段階で試す。
  - 最初の2週間：平日 1日1本（時間は固定）、週末は1本まで。
  - 次の2週間：平日 1日2本（時間を変えて）。
  - 比べるのは、1本あたりの表示回数（24時間後）と、リンクのクリック。1本あたりの数字が大きく落ちなければ、本数を増やしてよい。落ちるなら、減らす。
- 「1日1本が続けられること」と「1本ずつ質を保つこと」が先。本数は、あとから増やせる。
- **返信も、活動に数える**（見られ方に効くかは、公式には確かめていない）。投稿の直後は、返信に答えられる時間に出すのがよい。

## 2. 投稿の時間：生活パターンに合わせる
日本の目安（運用会社・ブログの記事。どれも根拠のデータは示されていない）：平日の7〜8時（通勤・通学）、12時前後（昼休み）、20〜22時（夜）。

このサイトの読者は、働く人・育児中の人・在宅の人など、生活が違う。**テーマごとに、読む人が起きている時間が違う**と考えて、試す。

| 時間帯 | 試す相手の例 |
|---|---|
| 朝 7:30 | 通勤・通学の人。短い知識（型C）・入口（型A） |
| 昼 12:15 | 昼休みの人。項目の紹介（型B）、調査の知らせ（型D） |
| 夜 20:30 | 仕事のあとの人。項目の紹介（型B）、海外・読み物（型F・G） |
| 夜 22:30 | 育児を終えたあとの人、夜型の人。子どもの権利・男女平等の項目（型B） |
| 週末 朝9:00／夜21:00 | 平日に見られない人。長めの読み物（型G） |

### 試し方（4週間）
1. 平日は、朝・昼・夜(20:30)・夜(22:30)を、曜日ごとに順に回す。型とテーマは、毎回記録する。
2. 1本ごとに、24時間後の数字を [X投稿の記録](../調査/X投稿の記録.csv) に書く。
3. 4週間後、時間帯ごと・型ごとの平均を見て、よかった時間に寄せる。
- X のアナリティクスは、運営者のアカウントの画面で見る。画面の名前・項目は変わることがあるので、見つからなければ教えてください。

## 3. フォローの方針
**目的を2つに分ける。**
1. **情報を集める**（公式の発表、議会・自治体・省庁・裁判所、報道、研究者）。
2. **関係をつくる**（同じ問題に取り組む人・団体、陳情に関心がある人）。

### 3-1. 情報を集めるには、フォローより「非公開リスト」
- X の「リスト」を非公開にして入れれば、フォローしないでも、タイムラインで読める。**フォロー数を増やさずに、情報源を何百も持てる。**
- リストの例：①議会の公式 ②自治体の公式 ③省庁・裁判所の公式 ④報道機関 ⑤研究者・専門家 ⑥同じ問題に取り組む団体。
- 反対の立場の公式アカウントも、リストに入れる。（記録のため。サイトの方針は両論の一次資料を点検すること）

### 3-2. 人・団体をフォローするとき
- **1日にフォローする数：最初の2週間は 1日5〜10件。慣れて反応があれば、1日20件まで。** それ以上は勧めない。
  - X の上限は1日400件（検索結果の要約。公式の「フォロー制限」のページが元。最新の数字は確かめていない）。これは**スパム判定の目安ではなく、機械的な上限**。一括フォロー、フォローしてすぐ解除するくり返しは、スパムとして扱われるおそれがある。
  - 総数が5,000に近づくと、フォロワーとの比率で制限される（二次資料）。まだ遠い。
- **フォローするのは、1件ずつ、理由があるアカウントだけ。** 理由は次のどれか。
  1. 運営者が自分の目で、公式のアカウントだと確かめた。
  2. 投稿を読んで、事実を大事にしていると感じた。
  3. 同じテーマで、やりとり（返信・引用）をしたい。
- **フォローしたあと、1週間のうちに、その人の投稿に1回、中身のある返信か引用をする。** フォローだけでは、気づかれない。
- 「フォロバ100」のような、フォロー返しを目的にした投稿・アカウントは、フォローしない。
- 議員は、地元の議会の議員を、サイトの議員名簿（`/letter`）や議会の公式ページで本人の公式のアカウントと確かめてから、必要に応じてフォローする。**特定の政党にかたよらないようにする。**

### 3-3. 候補の見つけ方
1. 議会・自治体・省庁・裁判所の公式アカウント：**Grok に一覧を頼む**（[依頼文](../../scripts/collect-prompt-grok.md) の B）。Grok の回答は、運営者が1件ずつ開いて、公式のアカウントか確かめる（認証済みの印や、公式サイトからのリンクで）。
2. 同じ問題に取り組む人：X の検索で「陳情」「請願」「意見書」「議会」と、各テーマの言葉（共同親権、DV、たばこ税など）を調べ、返信・引用の中身が丁寧な人を選ぶ。
3. フォローしている人・団体のフォローリスト（相手が公開しているもの）から、同じ関心の人を選ぶ。
4. 反応をくれた人。

### 3-4. 記録
- 誰を、いつ、なぜフォローしたかを、運営者の手元のメモ（`docs/非公開/` など）に残す。**個人のアカウント名は、公開のリポジトリに書かない。**

## 4. 4週間の進め方
| 週 | 投稿 | フォロー・リスト |
|---|---|---|
| 1 | 平日1日1本（朝または昼）。型A・Cを中心に | 公式アカウントを調べ、非公開リストを作る（Grok の一覧を確かめる）。フォローは1日5件 |
| 2 | 平日1日1本（夜20:30）。型Bを足す | リストを150件まで。フォローは1日5〜10件、返信を週に5件 |
| 3 | 平日1日2本（朝＋夜）。型D・Eを足す | フォローは1日10件まで。引用・返信を続ける |
| 4 | 平日1日2本（昼＋夜22:30）。週末は型G | 記録を見て、時間と型を決め直す |
