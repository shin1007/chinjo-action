# 陳情の項目を足す・直すときのルール

対象：`site/themes/*/asks-national.js`・`asks-local.js` の項目（1件＝1通の陳情）。
基本方針は [陳情の基本方針.md](陳情の基本方針.md)、一次資料のきまりは [CONTRIBUTING.md](../../CONTRIBUTING.md)。このファイルは、項目を足す・直すときの手順と点検の一覧です。

## 1. 足す前に決めること

- **向き**：国の制度の話は `scope: 'national'`（国への意見書を求める陳情）、自治体が自分でできることは `scope: 'local'`。1件の中で混ぜない。国と自治体の両方に頼みたいときは、2件に分ける（横浜市会・霧島市議会のように、意見書型と行政への要望型を分けて扱う議会がある。ほかの議会の扱いは確かめられていない）。
- **求める事項は1〜2点**（1件＝1通）。項目が多いと、1つでも反対があれば全体が不採択か継続審査になる。
- **出し先**：議会の判断が要るもの（条例・予算・新しい制度）は `route: 'chinjo'`、担当課が既存の事業の中で始められるものは `'yobo'`、どちらにもできるものは `'both'`（`yoboText` と `forStaff` が要る）。
- **住民でない人が出す場合**：住民以外の陳情は、審査せず議員に配るだけにする議会が多い。文面を足すときに「住民なら審査される」と前提しない。

## 2. 書くとき

1. **事実・数字・条文は、一次資料で確かめたものだけ**（法令の原文、官公庁・自治体・裁判所・国際機関の公式資料、論文の原文）。確かめた資料の URL と、どこに書いてあったか（ページ・条・表）をプルリクエストに書く。
2. 数字を入れた理由には、`refs` に**一次資料の URL つきの根拠が1つ以上**要る（`npm test` の `scripts/asks-audit.js` が確かめる）。
3. 解説・研究などの二次資料は、信頼できるものだけ。原文を開いて確かめ、`secondary: true` を付ける。二次資料だけで数字を書かない。
4. 一次資料で確かめられなかったことは書かない。`docs/調査/一次資料に当たれていない資料.md` に、取れなかった理由（BOT制限・サイトダウン・その他）と日付を書く。
5. 個人の事情・個人を特定できる情報は、陳情書に詳しく書かない。陳情書の写しは、議員・執行部のほか、報道機関や傍聴者にも配る議会がある（小山市・玉村町・軽井沢町・潮来市など）。
6. 言葉は穏やかに、事実は具体的に。反対側の主な懸念（たとえば DV・虐待の被害者への配慮）に、あらかじめ答えておく。
7. 理由は読み切れる長さに（目安は900字まで。超えると点検で「見直し」が出る）。本文は短く、出典は末尾の関連資料にまとめる。
8. 効果が確かめられていないことは、確かめられていないと書く（たとえば「分けて出せば行政に伝わりやすい」は未確認）。

## 3. 添付する根拠資料

- 陳情書に添える資料の扱いは議会ごとに違う（配付されるか、枚数の制限があるか）。足すときは、提出先の議会の案内を確かめる。この点の調査結果は [陳情の提出後の行政への伝わり方.md](../調査/陳情の提出後の行政への伝わり方.md) と同じ場所にまとめる予定。
- 添付する資料は、公開されても問題がないものに限る。

## 4. 足したあとの確認

```sh
npm test                    # 項目の形・refs の URL・根拠の有無（asks-audit）・文面の見本のずれ
node scripts/asks-audit.js  # 「直す」と「見直し」の一覧
npm run links               # refs の URL が開けるか（結果は scripts/.link-check.md。Git には入れない）
node scripts/refs.js        # 関連資料のページ（<テーマ>/refs.html）を作り直す
node scripts/samples.js     # 文面の見本（docs/見本/）を作り直す
node scripts/easy.js        # 「あらまし」とやさしい説明のページを作り直す（説明は themes/<テーマ>/easy.js に書く）
```

- `/trouble` の「一次資料で確かめられていないこと」を実態に合わせて直す。
- 項目の `id` は変えない（リンクが切れる）。

## 5. すでにある項目の見直し

- 年に数回、`npm run links` と `node scripts/asks-audit.js` を回す。
- 法令の改正・統計の更新・判例の追加があったら、該当する項目の数字と条文を、一次資料で確かめ直す。
- 長くなった理由（900字超）や、2点以上に見える求める事項は、分けるか削る。
