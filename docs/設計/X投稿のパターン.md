# X 投稿のパターン集（頻度・内容・組み合わせ）

2026-11-23。運営者が手で投稿するアカウント向け（自動投稿は必須としない）。サイトの実際の中身から作った。**頻度と反応の見込みについては、一次資料（X の仕様書など）で確かめたものはない。** 下の数字は私の提案で、まず試して、X のアナリティクスの数字で直す。

## 1. 頻度：どのくらい出すか
- **頻度は、[試し方](Xの時間とフォローの方針.md)に従って、2週間ごとに増やして確かめる**（最初は平日1日1本）。続かないなら、週3回に落とす。続けられる頻度が、いちばん大事。
- 4週間のあと、X のアナリティクス（表示回数・リンクのクリック・プロフィールのクリック・保存）を見て、反応のよかった型を増やし、悪かった型を減らす。
- 同じアカウントで、**一度に複数投稿を続けない**（1日に1〜2回まで）。同時に何本も出すと、タイムラインで埋もれる。

## 2. 繰り返しは問題ないか
**問題ありません。むしろ、必要です。** 理由：
- タイムラインの投稿は、数時間で流れる。同じ人の目に触れるのは、出した投稿のごく一部。
- フォロワーは毎日入れ替わる。新しい人は、過去の投稿を見ない。

**ただし、同じ文面のくり返しは避けます。** 同じ内容を、**切り口・書き出し・画像・リンク先を変えて**出す。同じ文面を続けて出すと、スパムとして扱われるおそれがある（X の規約は読めていない。二次資料による）。
- 同じ項目を取り上げ直すのは、**3週間あけてから**。
- 反応のよかった投稿は、書き出しを変えて、1〜2か月後に再度出す。

## 3. 内容のパターン（軸を組み合わせると、200本以上になる）
サイトには、陳情の項目が**全部で134項目**（国あて：男女平等15・子どもの権利22・日本人の権利15・国民の健康5・司法への参加9・その他10。自治体あて：男女平等18・子どもの権利18・日本人の権利11・国民の健康4・司法への参加2・その他5）あり、項目ごとに「この陳情の意義」のやさしい説明ページがある（例：`/dansei/easy/l_bias_men`。`l_` が自治体あて、`n_` が国あて）。

### 軸の掛け合わせ
- **テーマ**（6）×**型**（A〜G）×**書き出し**（問いかけ／数字／体験／よくある誤解／季節）。
- **季節・時期**：多くの議会は年4回の定例会（3・6・9・12月ごろ）を開く（議会ごとに違う。**確かめていないので、書くときは各議会の案内で**）。「次の定例会に向けて」の切り口は、時期ごとに使える。選挙の時期は、公職選挙法との関係を確かめるまで避ける。
- **写真・画像**：テーマごとの紹介画像（6テーマ×3枚）、郵送の GIF、項目の意義のページの画像（`og-image.png`）。

## 4. 1週間のリズム（例）
| 曜日 | 型 | 例 |
|---|---|---|
| 月 | B 項目（テーマの順に回す） | 子どもの権利の項目を1つ |
| 火 | C 知識 | 「陳情に紹介議員はいりません」 |
| 水 | A 入口 | 費用・手順・GIF |
| 木 | B 項目（別のテーマ） | 男女平等の項目を1つ |
| 金 | D または E | 調べた自治体の数／機能の更新 |
| 土 | F または G | 海外の請願、note の記事 |
| 日 | 休み、または反応への返信 | — |

6テーマを1周するのに6週。134項目を1回ずつ紹介すると、1日1本で約19週。

## 5. 書き方のきまり
1. **リンクは1投稿に1つ。** 長くなるときはスレッドにし、1件目で結論、2件目以降で根拠を書く。
2. **事実・数字は、サイトに載せているものだけ**（出典はサイトの項目の参考資料にある）。投稿の返信に、出典のリンクを付けてもよい。
3. 「確かめられていない」ことは、そう書く。
4. 特定の議員・政党・自治体・個人を批判しない（議員の名簿はサイトにあるが、投稿でメンションしない）。
5. 反応（返信・引用）は、運営者が読む。批判・質問には、必要なら一次資料で答える。答えられないことは、そう答える。
6. プロフィールに「運営者個人が運営（団体ではありません）」と書く。
7. ハッシュタグは1〜2個。「#拡散希望」は使わない（効果が確かめられていない）。

## 6. 文の例
文字数は、全角140字以内。

**A. 入口**
```
陳情は、500円足らずで出せます。
5件まとめて郵送しても約480円。登録不要・無料で、住所と氏名はサーバーに送りません。
印刷から投函までの流れは、50秒の動画で。
https://chinjo-action.vercel.app/
```

**B. 項目**（意義のページの内容を、1つの問いに）
```
「男性への思い込みは、研修や啓発で扱われていますか？」
施策を考える場で、男性の困難を指摘する意見も聴いてもらう。そんな陳情の項目を、やさしい説明つきで載せています。
https://chinjo-action.vercel.app/dansei/easy/l_bias_men
```

**C. 知識**
```
陳情に、紹介議員はいりません。誰でも、1通から出せます。
請願と陳情で、採択のされやすさは変わらないとされています（サイトの説明と出典はこちら）。
https://chinjo-action.vercel.app/about
```

**D. 調査の知らせ**
```
全国の1,787の議会のうち、郵送で受け付けると公式サイトで確かめられたのは、いまのところ一部です。
どの議会が確かめられていて、どこがまだなのかを、一覧にしています。
https://chinjo-action.vercel.app/coverage
```
（数字は、書くときの `/coverage` の最新の値に直す。）

**E. 運営の透明性**
```
このサイトには、まだ確かめられていないことが、いくつもあります。
「ここまでは確かめた／ここからは確かめられていない」を、運営者が公開しています。
https://chinjo-action.vercel.app/trouble
```

**F. 海外**
```
英国の議会の電子請願では、署名が1万に届くと政府が回答し、10万に届くと議会で討論されることがあります（英国議会の公式ページ）。
日本の陳情に、署名の数の基準はありません。違いを、note に書きました。
（note のリンク）
```
（日本の側の条文を e-Gov で確かめてから出す。To Do の 19a。）
