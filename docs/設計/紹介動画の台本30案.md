# 紹介動画の台本30案（No.7の声）

2026-11-23。台本の可変の5か所（1 出だし・2 対比・3 つなぎ・7 国への道・8 締め）の組み合わせで、30案＋現行（案00）。固定のコマは、4「確かめられた262の議会では、陳情は議員に届きます。」・5「署名を集める必要はありません。費用は、5件で、およそ480円です。」・6 手順の4コマ・9「『権利を守る陳情アクション』で検索してください。」。全体の構成は [紹介動画の台本案](紹介動画の台本案.md)。

## 見かた・作りかた
- 見比べる画像（5か所のコマを案ごとに並べたもの）：`python scripts/make-promo-video.py --sheet --out 出力先`
- 文の一覧：`python scripts/make-promo-video.py --list`
- 1案を動画にする：`python scripts/make-promo-video.py --pattern 7`（VOICEVOX を起動してから。全案は `--pattern all`。出力は `docs/見本/紹介動画/mail-howto-no7-p07.mp4` と `.srt`）。エンジンなしの確認は `--dry`（無音）。
- 型：共感型（案01〜06）は責めずに認める、問いかけ型（07〜12）は問いで始める、事実型（13〜18）は制度の違いを淡々と、強め（19〜24）は対比をはっきり、短く（25〜30）はコマの言葉を少なく。

## 使ってよい言い方・使わない言い方（根拠）
| 言い方 | 根拠（2026-11-23 に確かめた） |
|---|---|
| SNSへの書き込みは議会への提出ではない／請願や陳情は文書で議会に出す | 請願法第2条（氏名・住所を書いた文書で）、第3条（所管の官公署に提出）。陳情は法律に定めがなく、議会ごとに決まる |
| 議会に出せる意見（請願と陳情） | 憲法第16条（請願する権利）。陳情は `/about` |
| 議員に届く（262の議会） | `scripts/intake-reach.js`（公式サイトの案内で確かめた数。書き出す日に数え直す） |
| 署名を集める必要はない | 請願法・地方自治法第124条のどこにも署名の数の定めがない。`/about` の柏崎市の案内 |
| 議会が採択すれば、意見書として国に出されることもある／届くかもしれない | 地方自治法第99条（議会は意見書を国会又は関係行政庁に提出できる）。届くとは言い切らない |
| **使わない**：議員に読まれる、市長が確実に確認する、国を変えられる | 確かめられていない（`docs/調査/陳情の写しが執行機関に届く議会.md`） |
| **使わない**：井戸端などで、SNS の投稿者を責める言い方 | 見てほしい人に最後まで見てもらうため。案00の「井戸端」は強めなので、気になれば案01〜06を使う |
