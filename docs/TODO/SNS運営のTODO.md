# SNS（note と X）運営の TODO

最終更新：2026-11-23

陳情アクションの宣伝用に note と X のアカウントを作り、収益化できるものはする。1行が1ステップ。上から順に、済んだら `[x]` にする。個人情報（電話番号・メールアドレス・口座）は、このファイルに書かない。このプロジェクトは運営者個人が運営しており、団体ではない（各ページのフッターに明記）。SNS のプロフィールにも同じことを書く。

規約・手数料・収益化の条件は、公式ページが自動では開けなかった（[記録](../調査/SNS収益化の規約に当たれなかった資料.md)）。このリポジトリの方針では陳情の文面には二次資料を使わないが、SNS の運営の手続きについては、二次資料（解説記事・検索結果の要約）でも足りるとして進める。ただし、二次資料に基づく数字や条件には「二次資料」と付けて残す。

## 0. 先にやる：政治資金規正法（応援の受け付けの前提）
- [ ] 0a. 総務省の政治資金の案内（[記録](../調査/政治資金規正法と応援の受け付け.md)）を、ブラウザで開いて読む。「政治団体」の解説と Q&A を確かめる。
- [ ] 0b. 個人が運営するサイトが、運営費の応援を受けることが「政治団体」にも「政治活動に関する寄附」にも当たらないか、総務省か都道府県の選挙管理委員会に電話で聞く（聞いた日と答えを記録する）。
- [ ] 0c. 答えが出るまで、応援の受け付け・収益化（サポート・Premium・広告）は始めない。

## note
- [ ] 16. 2のメールアドレスで、note のアカウントを作る。名前・自己紹介（運営者個人、団体ではない、AI を使っていること）・アイコンを設定する。
- [ ] 17. 最初の記事を1本書く：「陳情とは何か、SNS への投稿と何が違うか」（`/about` を元にする）。終わりに、サイトへのリンクと、「陳情書づくりは無料」を入れる。
- [ ] 18. 記事は、Claude が `docs/投稿/note/` に下書きを置き、運営者が読んで画面に貼って公開する（公式の API は個人には使えないため）。頻度は、大きめの更新のときと、**2週に1本**のテーマ紹介（6テーマを順に。1周12週。続けられるなら週1本に）。
- [ ] 19. note の収益化（サポート・メンバーシップ・有料記事）の手続きと、本人確認・口座が要るかを公式ヘルプで確かめる。始めるのは 0c の後。収益は期待せず、有料にするのは本文以外（舞台裏の記録など）にとどめる。
