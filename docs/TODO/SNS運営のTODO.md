# SNS（note と X）運営の TODO

最終更新：2026-11-23

陳情アクションの宣伝用に note と X のアカウントを作り、収益化できるものはする。1行が1ステップ。上から順に、済んだら `[x]` にする。個人情報（電話番号・メールアドレス・口座）は、このファイルに書かない。

規約・手数料・収益化の条件は、公式ページが自動では開けなかった（[記録](../調査/SNS収益化の規約に当たれなかった資料.md)）。このリポジトリの方針では陳情の文面には二次資料を使わないが、SNS の運営の手続きについては、二次資料（解説記事・検索結果の要約）でも足りるとして進める。ただし、二次資料に基づく数字や条件には「二次資料」と付けて残す。

## 運営者が手元でやること（先に）
- [ ] 1. 使っていない電話番号を、X のアカウント用に使うと決める（SMS が受け取れる状態か確認する）。
- [ ] 2. 陳情アクション用のメールアドレスを1つ決める（運営者の個人のものと分ける）。
- [ ] 3. アカウント名（表示名とID）を決める。サイトの名前（権利を守る陳情アクション）と合わせる。
- [ ] 4. アイコンとヘッダーの画像を決める（`site/og-image.png`・`site/favicon.svg` を流用できる）。

## X
- [ ] 5. 2のメールアドレスと1の電話番号で、X のアカウントを作る。
- [ ] 6. プロフィール文を書く（サイトの URL、「陳情書づくりは無料」、運営は個人であること）。
- [ ] 7. 自動化されたアカウントとして表示する必要があるか、Xの自動化の規約で確かめる。
- [ ] 8. 固定ポストを1本書く（陳情とは何か＋サイトへのリンク）。
- [ ] 9. 最初の1週間の投稿を5本書く（新しい項目、調べた自治体、提出の流れ）。事実・数字は出典つきで。
- [ ] 10. 収益化の条件（Premium の加入、フォロワー数、インプレッション）を、公式ヘルプをブラウザで開いて確かめ、結果をこのファイルに書く。
- [ ] 11. 条件を満たせそうなら、Premium に加入するかを決める。

## note
- [ ] 12. 2のメールアドレスで、note のアカウントを作る。
- [ ] 13. クリエイターページの名前・自己紹介・アイコンを設定する。
- [ ] 14. 最初の記事を1本書く：「陳情とは何か、SNS への投稿と何が違うか」（`/about` を元にする）。
- [ ] 15. 記事の終わりに、サイトへのリンクと、「陳情書づくりは無料」「応援は任意で、内容は変わらない」を入れる。
- [ ] 16. note の収益化（サポート・メンバーシップ・有料記事）を始める手続きと、本人確認・振込先の口座が要るかを、公式ヘルプで確かめる。
- [ ] 17. 無料のまま続けるものと、有料にするもの（舞台裏の記録・読み物など。陳情書づくりの本文は無料のまま）を分けて決める。

## サイトに出す（準備中のまま止める）
- [ ] 18. アカウントができたら、`/trouble#support` の「応援の方法」の下にリンクを出す（いまは `/trouble` の「準備中のこと」に「準備中」と書いてある）。
- [ ] 19. トップページ `/` のフッターにも、X と note のリンクを出す。
- [ ] 20. `/trouble` の「準備中のこと」の SNS の項目を、開設した旨に書き換える。
- [ ] 21. 収益化を始めたら、`/tokushoho` と `/privacy` に、受け取る収益と外部サービスへの送信（X・note）を書く。

## 税・お金
- [ ] 22. 収益が出たときの扱い（雑所得・事業所得、年間の金額のめやす、確定申告の要否）を、国税庁の公式の案内で確かめる。
- [ ] 23. 収益と運営費（Claude の利用料）の月ごとの記録を、`docs/非公開/` に付け始める。

## 続けるきまり
- 同じ文面の大量投稿・自動の連投・フォロワーの購入はしない。
- 応援・収益で、陳情の内容や載せる資料は変えない。
- 選挙期間中の投稿は、公職選挙法との関係を確かめてから（未確認）。
