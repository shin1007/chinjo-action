## 順序の注意

- 政治資金規正法の確認（[聞く](運営者/聞く（専門家・窓口）.md) の 0b と [開いて確かめる](運営者/開いて確かめる.md) の 0a）が済むまで、応援の受け付け・収益化（[手続き・設定・記録](運営者/手続き・設定・記録.md)・[書く・投稿する](運営者/書く・投稿する.md)）は始めない。
- 「手続き・設定・記録」の X・note の設定は、[決める](運営者/決める.md) の電話番号・メールアドレス・アカウント名（SNS運営 1〜4）が決まってから。
