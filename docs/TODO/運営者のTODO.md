## 指摘への対応で、運営者が決める・行うこと

- [ ] 1. **独自ドメインを取得する**（vercel.app の仮のアドレスのまま。議会に出す書類を作るサイトとして、信頼感が弱い）。取得して Vercel に結びつけたら、教えてください。canonical・og:url・og:image・QR コードのアドレス（`site/`・`templates/`・`scripts/`・`test/` にある chinjo-action.vercel.app）を、まとめて置き換えます。旧アドレスから新アドレスへの転送（vercel.json）も入れます。費用は [資金調達と税金のTODO](資金調達と税金のTODO.md) の運営費に含める。
- [ ] 2. **外部送信の規律（電気通信事業法第27条の12）が、このサイトに当たるかを確かめる**。総務省の窓口か、弁護士に聞く（聞いた日と答えを記録）。答えが出たら、`/trouble` の「運営のこと」と `/privacy` を直します。
- [ ] 3. **法律の専門家に文面を見てもらう**（運営者は弁護士ではない、と `/trouble` に書いている）。見てもらう範囲（まず子どもの権利テーマ）を決める。
- [ ] 4. **応援の受け付け方法を決める**（[資金調達と税金のTODO](資金調達と税金のTODO.md)）。「運営費の支援の導線が弱い」という指摘への答えは、決まるまで出せない。
