# 外部レビュー用の資料

作成日：2026-11-11

市民が地方議会に出す陳情書や役所に出す要望書の文面を作るサイト（陳情アクション）の、陳情項目・参考資料・文面を、テーマごとのフォルダに分けたものです。外部の AI に、資料の適切さ・より良い資料・足すべき項目を見てもらうために作りました。

## フォルダ

| テーマ | フォルダ | 項目数 | 参考資料 |
|---|---|---|---|
| 男女平等を求める陳情アクション（dansei） | 男女平等を求める陳情アクション/ | 27 | 83 |
| 国民の健康を守る陳情アクション（kenko） | 国民の健康を守る陳情アクション/ | 9 | 33 |

| 司法に国民の声を届ける陳情アクション（shiho） | 司法に国民の声を届ける陳情アクション/ | 11 | 38 |
| 税の公平と教育を守る陳情アクション（sonota） | 税の公平と教育を守る陳情アクション/ | 10 | 41 |

各フォルダの中身：
- `項目と参考資料.md`：項目ごとの求めること・理由・参考資料（題名・URL・根拠にした所）
- `陳情書と要望書の文面.md`：サイトが作る陳情書（議会あて）と要望書（市長あて・自治体あての項目のみ）の文面（1項目1通）

英語の資料の原文と訳は `docs/英語の参考資料の訳.md`、原文を確かめられなかった資料は `docs/一次資料に当たれていない資料.md` にあります。

## 渡し方

1. `Grokへのプロンプト.md` の依頼文を貼る。
2. テーマを1つ選び、そのフォルダの `項目と参考資料.md` と `陳情書と要望書の文面.md` を添付する（1回に1テーマ）。
3. 英語の資料の読み違いも見てもらうなら、`docs/英語の参考資料の訳.md` も添える。

作り直すとき：`node scripts/review-pack.js`
