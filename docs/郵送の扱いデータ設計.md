# 郵送・持参による陳情の扱い

## 正本の形

`data/mail-policy.js` の `window.MAIL_POLICY` を正本にする。キーは既存データと同じ都道府県・市区町村（都道府県議会は `@`）で、1件は次の形を持つ。

```js
{
  mail_resident: 'ok' | 'distribute' | 'unknown',
  mail_nonresident: 'ok' | 'distribute' | 'unknown',
  hand_nonresident: 'ok' | 'distribute' | 'unknown',
  source_quote: '公式ページの原文',
  source_url: 'https://...',
  note: '在勤・在学、FAX、議長判断など',
  verified_at: 'YYYY-MM-DD',
  confidence: 'confirmed' | 'likely' | 'unknown'
}
```

`mail.js` の配列は互換入力として `MailPolicy.get()` が変換する。新たに確認したデータは `MAIL_POLICY` に追加し、同じ議会の `mail.js` は重複して更新しない。

## 移行対応表

| 旧判定 | mail_resident | mail_nonresident | hand_nonresident |
| --- | --- | --- | --- |
| `ok` | `ok` | `ok` | `unknown` |
| `jisan` | `distribute` | `distribute` | `unknown` |
| `outside` | `ok` | `distribute` | `unknown` |
| `none` | `distribute` | `distribute` | `unknown` |

旧配列の第2要素と第3要素は、それぞれ `source_quote` と `source_url` に移す。旧値は機械的な移行値なので、非住民・持参の根拠が原文にない場合は、個別確認で `unknown` に戻す。

## 貢献フローと公開条件

[`/contribute.html`](../contribute.html) で都道府県・議会を1つ選び、公式URL、3つの選択肢、任意の原文・備考、確認日を入力する。画面は確認内容と保存用データを出力するだけで、送信・即時公開はしない。

管理者は、同じ議会に複数回答がある場合、`source_url` と `source_quote` があるもの、`confidence` が `confirmed` のもの、`verified_at` が新しいものをこの順で優先する。原文とURLがない回答は公開データに採用せず、体験談だけの回答は根拠データと分ける。

## 表示

表示側は `MailPolicy.get()` を使い、`unknown` は「未確認。提出前に議会事務局へ確認」とする。根拠URLがある場合は「公式案内の根拠を見る」を表示する。制度は変わり得るため、根拠があっても提出前確認を促す。
