# 陳情の基本方針 ― 採択されやすい陳情のつくり方

最終調査日：2026年11月4日

このサイトで作る陳情書・請願書・要望書の文面や機能は、この方針に沿って設計する。
各議会の公式案内、議員による解説、実際に可決された意見書の事例、反対側の主張を調べ、その結果から方針を決めた。

---

## 1. 結論：8つの基本方針

1. **国への要望と自治体への要望を分ける。**
   法律や国の制度の話は「国へ意見書を出してほしい」という陳情にする。自治体あての陳情には、その自治体が自分の判断でできることだけを書く。
2. **1通の陳情で求めることは1〜2点に絞る。**
   委員会は「願意が妥当か」と「実現できるか」を項目ごとに判断する。項目が多いと、1つでも反対があれば全体が不採択か継続審査になる。
3. **言葉は穏やかに、事実は具体的に書く。**
   これまで可決された意見書の題名は「面会交流の環境整備」「親子の断絶を防止する法整備」など、穏やかなものが多い。強い言葉は陳情書の本文に使わず、事実と出典で示す。
4. **DV・虐待への配慮を最初に書く。**
   反対意見の中心は「DV・虐待の被害者が危険にさらされる」という懸念にある。「真に保護が必要な場合を除き」を必ず入れて、反対する理由をなくす。
5. **確実に審査してほしい議会には、持参するか、紹介議員をつけて請願にする。**
   郵送や市外からの陳情は「議員に写しを配るだけ」になる議会が多い。地元の議会には、紹介議員をつけた請願を基本にする。
6. **提出の前に、担当課と議員に相談する。**
   担当課と意見交換していること、議員が内容を理解していることは、採択されやすい陳情の条件として議員自身が挙げている。
7. **個人の事情は陳情書に詳しく書かない。**
   多くの議会は「個人のプライバシーにかかわるもの」「係争中・調停中の事件に関するもの」を審査の対象から外す基準を持っている（千葉市・神奈川県・八千代市・鎌倉市・和光市など）。陳情書の本文には2〜3文の一般的な表現だけを書き、詳しい事情は公開されない議員への手紙や面談で伝える。
8. **同じ地域でまとめて出し、採択されたら広める。**
   可決された事例は、同じ時期に近くの自治体で続けて出ている。1つの議会で採択されたら、その事実を近隣の議会への陳情に書き加える。

## 2. 制度上の事実（各議会の公式案内から）

| 事実 | 出典 |
|---|---|
| 請願か陳情かで採択のされやすさは変わらない。紹介議員がいるかどうかも審査結果とは関係しない、と議会自身が回答している。 | [柏崎市議会 Q&A](https://www.city.kashiwazaki.lg.jp/soshikiichiran/gikaijimukyoku/qa_kashiwazakishigikai/31502.html) |
| 署名を何人分集めれば採択される、という基準はない。 | 同上 |
| 採択の基準は「願意が妥当で、法令上・行財政上実現できるか」。採否は委員会と本会議の多数決で決まる。 | [習志野市議会](https://www.city.narashino.lg.jp/soshiki/giji/gyomu/shigikai/seigan.html) |
| 陳情については採択・不採択を決めない議会もある。 | [宮城県議会](https://www.pref.miyagi.jp/site/kengikai/seigan.html) |
| 郵送や市外から出された陳情は、審査されず写しを配るだけ、または報告するだけの議会がある。 | [相模原市議会](https://www.sagamihara-shigikai.jp/doc/2013120600324/)、[新潟市議会](https://www.city.niigata.lg.jp/shigikai/index_annai/annai_seigan_tinjou.html)、[国立市議会](https://www.city.kunitachi.tokyo.jp/soshiki/Dept09/Div01/Sec02/gyomu/0293/1461060255267.html)、[新見市議会](https://www.city.niimi.okayama.jp/gyosei/gyosei_detail/index/258.html) |
| 意見書を求める陳情・請願が採択されると、委員会の議員が意見書案を出し、本会議で可決されれば国などへ送られる。 | [岩倉市議会](https://www.city.iwakura.aichi.jp/gikai/0000002135.html) |
| 議長、副議長、所管する常任委員会の委員長は、紹介議員になれない（京都市会の例）。 | [京都市会](https://www2.city.kyoto.lg.jp/shikai/seiganchinjo/index.html) |

### 議員から見た「採択されやすい陳情」

議員の解説記事（[高橋将「陳情・請願のリアルな扱い方」2025年5月](https://note.com/q_owl/n/n2d99f3aa7f80)）は、次の5つを採択されやすい条件に挙げている。

- 目的や背景が明確である
- 実現できる範囲に収まっている
- 署名や地域団体の声など、社会的な広がりがある
- 担当課と一定の意見交換がされている
- 議員が内容を理解し、議会の中で共有できるよう準備されている

同じ記事は、次のようにも書いている。
- 内容があいまいなもの、行政の範囲外と判断されたものは、継続審査や採択見送りになる。
- 紹介議員がいても不採択になることはある（「紹介人＝保証人ではない」）。
- 議員には、意図のずれの確認、現実的な修正、委員会での背景説明、出し方の助言を頼める。

## 3. 成功事例：可決された意見書

### 3-1. 可決された議会の一覧

親子ネットのまとめ（[oyakonet.org/chinjo](https://oyakonet.org/chinjo/)）によると、会員などの陳情・請願をきっかけに、多くの議会が意見書を国へ提出している。意見書は次の2種類。

- 「別居・離婚後の親子の面会交流の法制化と支援を求める意見書」
- 「離婚後の共同親権・共同監護の法制化を求める意見書」

可決の時期は、大きく4つの波に分かれる。

| 時期 | 主な議会 |
|---|---|
| 2008〜2011年（平成20〜23年） | 東京都の多摩地域（国立・小金井・日野・立川・国分寺・小平・清瀬・狛江・昭島）、杉並区、埼玉県と県内の市（さいたま市・新座市・白岡市）、名古屋市、大阪府、兵庫県、滋賀県、西宮市、岸和田市、沖縄県の名護市など |
| 2015〜2017年（平成27〜29年） | 千葉県と県内の市、茨城県の市（常総・坂東・古河・下妻）、世田谷区、北海道と道内の市（岩見沢・砂川）、沖縄県の市（豊見城・南城・糸満） |
| 2020〜2021年（令和2〜3年） | 神奈川県と県内の市（横浜・大和・座間・秦野・海老名・伊勢原）、千葉市、佐倉市、白井市、静岡県、富士宮市、埼玉県 |
| 2024年（令和6年） | 座間市（3月） |

具体的な意見書の例：
- 横浜市議会は2020年（令和2年）第4回定例会で「別居、離婚後の親子の面会交流についての環境整備を求める意見書」を可決している。2010年（平成22年）にも「離婚後の親子の面会交流の充実を求める意見書」を可決している（[横浜市](https://www.city.yokohama.lg.jp/shikai/kiroku/kekka/kaketsu.html)）。
- 豊見城市議会は2016年（平成28年）に「別居・離婚後の親子の断絶を防止する法整備に関する意見書」を可決している（[豊見城市](https://www.city.tomigusuku.lg.jp/material/files/group/38/h28-ikennsyo5gou.pdf)）。検索結果の要約によれば、子の連れ去りの禁止、フレンドリーペアレント・ルール（他方の親に寛容な親を親権者として重視する考え方）、離婚時の共同養育計画（親子交流と養育費の取り決め）の義務化を求めている。ただし本文PDFは読み取れず、原文はまだ確認していない。

### 3-2. 事例から読み取れること

- **同じ地域で続けて可決されている。** 多摩地域、千葉・茨城、神奈川など、同じ地域で同じ時期にまとまって可決されている。同じ地域の当事者が連携し、ほぼ同じ文面を近くの議会へ出したと考えられる。→ **方針8**
- **都道府県議会と、県内の市の議会が連動している。** 千葉県と千葉県内の市、神奈川県と神奈川県内の市、北海道と道内の市、埼玉県と県内の市。
- **題名が穏やかである。** 大きな市の議会で通ったものは「面会交流についての環境整備」「親子の断絶を防止する」など、子どもの利益を前に出し、誰かを非難しない題名になっている。→ **方針3**
- **2024年の法改正の後は、国への意見書の役割が変わった。** 改正民法が2026年4月に施行され、「共同親権を法制化してほしい」という意見書はすでに目的を果たした。これからの国への意見書は、施行後の運用の改善と見直しを求める内容にする。

## 4. 施行後の新しい論点：自治体が自分でできること

改正民法の施行から半年後に書かれた記事（[牧野佐千子「共同親権から半年、地方自治体に残された7つの宿題」アゴラ 2026年9月30日](https://agora-web.jp/archives/260929082841.html)）は、国の法改正を待たずに自治体が自分でできることを7つ挙げている。自治体あての陳情のテーマとして、そのまま使える。

| # | 論点 | 自治体ができること | 記事が挙げる先行例 |
|---|---|---|---|
| 1 | 首長の立ち位置 | 共同親権の世帯だけでなく、単独親権のままの別居親にも、同じ説明が届くようにする | ― |
| 2 | 学校行事への別居親の参加 | 「原則として参加を認める」という教育委員会の通知・ガイドラインを出す | 大東市（施行日に文書を出した）、世田谷区（9月の議会で答弁）、目黒区、千葉市 |
| 3 | 転居届・転入届 | 市の届出用紙に他方の親の同意を確かめる欄を設ける。DV・虐待から急いで逃げる場合は例外にする | ― |
| 4 | 災害時の連絡先 | 学校・園の緊急連絡先に別居親を「原則として加え、外す条件だけを決める」 | ― |
| 5 | 親子交流と養育費の支援 | 交流支援を父母の合意の前の段階（相談・立会い・送迎）まで広げる。養育費の取決め率と受給率を指標にする。窓口職員の研修 | 横浜市（交流支援事業はあるが、父母の合意が前提） |
| 6 | DV支援措置（住民票の閲覧制限） | 本当の被害者を守りつつ、第三者による点検と、誤って適用された場合に正す手続きを設ける | ― |
| 7 | 縦割り行政 | 全体をまとめる部署か、部署をまたぐ会議を置き、数字の指標と工程表を持つ | ― |

**方針への反映：** 自治体あての陳情は、この表から1〜2点を選ぶ。とくに2（学校行事）と4（災害時の連絡先）は次の理由で採択されやすいと考えられる。
- 予算がほとんどかからない
- 国が示したQ&Aと先行例という根拠がある
- DVとの関係で反対されにくい（「安全上の支障がない限り」と書ける）

## 5. 反対側の論点と、それにどう応えるか

| 反対側の主張 | 出典 | 陳情書での応え方 |
|---|---|---|
| DVは立証が難しく、加害者を共同親権から確実に外せない | [埼玉弁護士会 会長声明 2024年5月](https://www.saiben.or.jp/proclamation/001340.html) | 改正民法は、DV・虐待のおそれがあれば家庭裁判所が必ず単独親権とする仕組みになっていると書く。そのうえで、自分たちの要望は「真に保護が必要な場合を除く」ものだと明記する |
| DV防止策やひとり親支援が後退する | [全国女性シェルターネット 2024年2月](https://nwsnet.or.jp/wp-content/uploads/2024/02/a8a5f6f7c7e43a70720b64af54e5a26f.pdf) | 養育費の確保や交流支援は、ひとり親家庭の負担を軽くする方向の施策だと示す。経済的な数字を使う（養育費を受け取っている母子世帯は28.1%） |
| 共同親権の導入中止を求める署名が約22万6千筆集まった | [s-newscommons 2024年](https://s-newscommons.com/article/2091) | 国の制度はすでに施行されている。いま問うべきは「施行された制度を、子どもの利益のためにどう運用するか」だと設定し直す |
| 審議が拙速だった | [自由法曹団 2024年](https://www.jlaf.jp/04seimei/2024/0517_1727.html) | 施行後の実態を調べ、運用を見直すよう求める（反対側も否定しにくい要望になる） |

**反対意見を受けにくくする書き方：**
- 性別の対立にしない。子と引き離される母親もいる。
- 「子どもの権利」「子どもの最善の利益」を主語にする。
- 誰か（相手方、弁護士、行政）を非難するのではなく、制度や運用の問題として書く。

## 6. 表現の方針

このサイトの利用者が強く問題にしていることを、議会で採択されやすい表現に言い換える。

| 伝えたいこと | 陳情書の本文での表現 | 強い表現を使える場面 |
|---|---|---|
| 実子誘拐 | 「正当な理由のない子の連れ去り」「一方的な子連れ別居」 | 題名は使わない。本文に「いわゆる実子誘拐」と一度だけ書く程度 |
| 起訴に至らない | 最高裁 平成17年12月6日決定（親による連れ去りでも略取罪が成立し得る）を示し、「実際には捜査・起訴に至る例は少ないと指摘されている」と書く | 起訴件数を書く場合は検察統計・国会答弁などの出典が必須 |
| 男女共同参画局が連れ去りを案内している | 「国の広報が安全確保の手順を示す一方、親子関係への影響を説明していない」と、該当ページのURLと閲覧日を添えて書く | 議員に渡す資料に、画面の写しとともに載せる |
| 弁護士が婚姻費用・養育費をピンハネしている | 「子のための給付の一部を報酬に充てる報酬体系がある」と、公開されている報酬規程を出典に書く | 特定の事務所名は、どの場面でも書かない |
| 離婚弁護士の禁止 | 「葛藤を不必要に高める弁護活動の規制」「子の利益を最優先とする職務規範の整備」 | ― |

陳情書は公文書として公開される。断定や非難は、名誉毀損と受け取られるおそれがあり、不採択の理由にもなる。強い問題提起は、議員と直接会うときや、議員に渡す資料で行う。

## 7. 提出の進め方（チェックリスト）

1. **テーマを決める**
   - 国への意見書（運用の改善・見直し）か、自治体の施策（第4章の表から1〜2点）かを選ぶ。
2. **議会の決まりを調べる**
   - 締切（定例会の告示の前が多い）
   - 郵送・市外からの陳情の扱い
   - 指定の様式、押印が必要か
3. **事前に相談する**
   - 担当課（学校のことなら教育委員会、届出のことなら市民課など）に現状を聞く。
   - 賛同してくれそうな議員に会い、紹介議員を頼む。会派をまたいで頼めると、なお良い。
4. **文面をつくる**
   - 題名は穏やかにする。
   - 求める事項は1〜2点。
   - DV・虐待への配慮を明記する。
   - 事実には出典を付ける。
   - 近くの議会や、同じ都道府県の議会で採択された例があれば書き加える。
5. **提出する**
   - 地元の議会：持参するか、紹介議員をつけた請願にする。
   - 遠くの議会：郵送でもよい。写しを配るだけでも、全議員の目に触れる。
6. **委員会の審査に臨む**
   - 委員会を傍聴する。意見陳述ができる議会では、3〜5分で話せる原稿を用意する。
7. **結果を広める**
   - 採択されたら、意見書の本文、議決の日、議会名を公開し、次に陳情する人が引用できるようにする。
   - 不採択・継続審査になったら、その理由を議事録で確認し、次の定例会で出し直す。

## 10. 実子誘拐・男女共同参画をめぐる現状の問題点と、陳情への落とし込み

問題点はそのまま書かず、「自治体・国がすでに持っている制度の運用を整える」形に置き換えると採択されやすい。DV被害者の安全確保を必ず前提に置く。

| 現状の問題点 | 陳情での求め方 | 項目（data/） |
|---|---|---|
